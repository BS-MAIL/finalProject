# 5단계: HWPX 검증과 제출 기록

## 목적

생성된 HWPX가 확정 Markdown과 같은 6차시 내용을 담고, 기존 템플릿의 표·수식·쪽 구성과 활동지·예시 결과지 삽입 상태를 유지하는지 확인한다. 이 단계가 통과한 파일만 제출용 HWPX로 공유한다.

## 사용할 기록

- 파이프라인 기준: [`PIPELINE.md`](PIPELINE.md)
- 검증 보고서 양식: [`HWPX-검증-보고서.md`](HWPX-검증-보고서.md)
- 최종 HWPX, 템플릿, 역추출 Markdown, PDF·이미지 렌더링본은 별도 작업 폴더에 둔다.

## 검증 순서

1. 생성 담당자가 4단계의 생성 요청서와 최종 HWPX 파일명·버전·SHA-256을 전달한다.
2. HWPX를 실제 한글 프로그램으로 열고, 단원 1~4·표·수식·머리말·쪽 구성이 깨지지 않는지 확인한다.
3. `unzip -t 최종파일.hwpx`로 ZIP 패키지 무결성을 확인한다.
4. `kordoc 최종파일.hwpx -o 역추출.md --silent`으로 Markdown 역추출본을 만든다.
5. 확정 Markdown과 제목, 교사, 학년, 과목, 단원, 성취기준, TRACES 1~6차시, 산출물, 평가 증거, 안전·개인정보·AI 경계를 대조한다.
6. HWPX를 PDF 또는 페이지 이미지로 내보내 실제 쪽을 검수한다.
7. 특히 활동지·교사용 예시 결과지의 이미지 해상도·삽입 위치·학생용/교사용 구분, 표 잘림, 수식 깨짐, 글자 겹침을 확인한다.
8. 검증 결과와 차이·재생성 조치를 보고서에 기록하고, 통과 전에는 배포 보류로 표기한다.

## 제출용 HWPX 판정 기준

- [ ] HWPX가 열리고 ZIP 무결성 검사를 통과했다.
- [ ] 템플릿의 표 구조·수식 영역·머리말·쪽 구성이 의도대로 유지된다.
- [ ] 역추출 Markdown이 확정 수업안과 제목·6차시·성취기준·산출물·안전 경계에서 일치한다.
- [ ] 학생용 활동지와 교사용 예시 결과지가 올바른 위치에 있고 서로 분명히 구분된다.
- [ ] 확정 Markdown 또는 승인된 부속자료에 없는 문장, 승인되지 않은 내용, 미확정 제안, 빈 입력칸이 없다.
- [ ] 검증 보고서에 템플릿 버전, 생성 엔진, 최종 파일 버전, SHA-256, 통과·보류 판정을 기록했다.
