# 5단계: HWPX 검증과 제출 기록

## 목적

생성된 HWPX가 열리고, 확정 Markdown의 내용과 일치하며, 표·수식·활동지 이미지·쪽 구성이 실제로 사용할 수 있는 상태인지 검증한다. 검증이 끝난 뒤에만 제출용 파일로 확정한다.

## 사용할 양식

[`../templates/HWPX-검증-보고서.md`](../templates/HWPX-검증-보고서.md)를 복사해 교사별 검증 보고서를 작성한다. HWPX와 역추출본은 별도 작업 폴더에 보관하고, 이 저장소에는 검증 보고서 Markdown만 둔다.

## 검증 순서

1. HWPX를 실제 한글 프로그램 또는 승인된 문서 도구로 열어 본다.
2. `unzip -t 최종파일.hwpx`로 ZIP 패키지 무결성을 확인한다.
3. `kordoc 최종파일.hwpx -o 역추출.md --silent`으로 Markdown 역추출본을 만든다.
4. 확정 Markdown과 제목, 교사, 학년, 과목, 단원, 성취기준, 총 차시, 차시별 활동·산출물·평가 증거를 대조한다.
5. HWPX를 PDF 또는 페이지 이미지로 내보내고 실제 페이지를 열어 본다.
6. 표 잘림, 수식 깨짐, 글자 겹침, 활동지 이미지 해상도·위치, 학생용/교사용 예시 구분, 머리말·쪽 번호를 확인한다.
7. SHA-256, 템플릿 버전, 생성 도구·버전, 생성·검증 시각, 발견 차이와 조치를 검증 보고서에 기록한다.
8. 실패나 미확인 항목이 있으면 배포 보류로 표기하고 새 버전으로 재생성한다.

## 완료 기준

- [ ] HWPX가 열리고 ZIP 무결성 검사를 통과했다.
- [ ] 역추출 Markdown이 확정 수업안과 제목·6차시·성취기준·산출물·안전 경계에서 일치한다.
- [ ] 표·수식·출처·활동지 이미지·쪽 구성을 실제 렌더링 결과에서 확인했다.
- [ ] 원문 근거 없는 문장, 미확정 제안, 빈 입력칸이 없다.
- [ ] 검증 보고서에 파일명·버전·SHA-256·도구·템플릿·판정을 기록했다.
- [ ] 배포 가능 판정 뒤에만 제출용 HWPX를 공유했다.
