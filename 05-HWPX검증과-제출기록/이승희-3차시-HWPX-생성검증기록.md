## 부속자료와 남은 제약

- 학생·교사 HTML 6종 및 PNG 18개 각각의 절대 경로, 학생/교사 구분, 해당 차시 부록 수동 삽입 예정 위치를 COMMON 자료 목록에 넣었다.
- **PNG 18개는 HWPX에 미삽입**이다. 엔진 미지원 기능을 임의 XML 개발로 추가하지 않았다. 기존 한글에서 학생용과 교사용을 구분해 수동 삽입·크기·쪽 나눔 확인이 필요하다.
- kordoc 대신 모든 hp:t 역추출·원문 행 대조를 수행했다. 이는 내용 보존 검사이며 줄바꿈·표 잘림·수식 시각 모양·페이지 유출의 동등 검사가 아니다.
- 템플릿 표 셀 주소·병합·수식 영역을 직접 변경하지 않고 기존 엔진만 사용했다. 원문의 긴 문단·표를 기존 셀에 그대로 보존해 **과도하게 긴 셀과 공통 정보 반복**이 생길 수 있다. 한글에서 열렸다는 사실만으로 읽기 좋은 조판을 보장하지 않는다. PDF를 사람이 확인하고 필요하면 내용 의미를 보존하는 승인된 편집을 해야 한다.
- 학교·일시·장소와 종목별 상세 규격은 미확정이다. 앱 기능은 설계 전제일 뿐 이번 HWPX 작업에서 검증하지 않았다. 수업 실행·모두의 즐거움·행사 성공을 주장하지 않는다.
- 최종 배포 판단, PDF 전체 시각 검수, 부속자료 수동 삽입, 템플릿 잔여 정리 및 사용자 확인은 부모 최종 검토 범위로 남긴다.
