# MAIL CBL 최종 제출: 6차시 수업지도안 제작

이 저장소는 MAIL 동아리 구성원이 교사별로 CBL 수업 주제 하나를 골라 **TRACES 6차시 수업지도안, 활동지·예시 결과지, 제출용 HWPX와 검증 기록**까지 완성하는 작업 공간입니다.

루트에는 이 안내만 둡니다. 모든 작업 안내·양식·기록은 작업 순서에 맞는 폴더에 있습니다. HWPX, HTML, PDF, PNG, 템플릿 바이너리와 생성 엔진은 별도 생성 작업 폴더에 두며 이 저장소에는 Markdown만 보관합니다.

## 최종 목표

각 교사는 다음을 하나의 흐름으로 완성합니다.

1. 기존 피드백을 반영하고 수업 주제 하나를 확정합니다.
2. `Trigger → Research → Architect → Change-plan → Execute → Study`의 TRACES 6차시 수업안을 확정합니다.
3. 차시별 학생 활동지와 교사용 예시 결과지를 설계하고 HTML에서 PDF·PNG로 만듭니다.
4. 승인된 HWPX 템플릿과 이전 생성 엔진 방식으로 제출용 HWPX를 생성합니다.
5. 열기·ZIP 무결성·역추출·페이지 렌더링 검증을 마친 뒤 제출합니다.

## HWPX 생성 원칙

- 이전 `club-plan` 저장소에서 사용한 CBL 생성 자산은 **승인 템플릿 `form_template.hwpx` + `build_engine.py` + `content.py`** 구조입니다.
- `content.py`는 차시 공통 정보 `COMMON`과 차시별 정보 `CHASI[1]`~`CHASI[6]`으로 작성합니다.
- 생성은 템플릿 원본이 아니라 복사본으로 하고, 1개 차시 시험 생성 뒤 1~6차시 통합 제출용 HWPX를 생성합니다.
- 템플릿의 표·셀 주소·수식 영역을 임의로 바꾸거나 HWPX ZIP/XML을 문자열 치환하지 않습니다.
- 생성 후에는 HWPX를 실제로 열고, `unzip -t`, `kordoc` 역추출, PDF·페이지 렌더링 검수를 모두 수행합니다.
