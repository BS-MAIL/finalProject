# 1단계: 피드백 반영과 주제 선정

## 목적

교사별로 CBL 수업 주제를 **하나만** 정하고, 기존 원문·피드백·교사 확인 사항을 분리한다. 이 단계에서 만든 결정이 이후 TRACES 6차시 수업안, 활동지, HWPX의 기준이 된다.

## 입력

- [`../원문보존/`](../원문보존/): 기존 HWPX에서 추출한 원문 Markdown. 읽기 전용이다.
- [`../교사용-CBL-수업안-개선-안내문.md`](../교사용-CBL-수업안-개선-안내문.md): 기존 초안 보완 기준
- [`../동아리-CBL-수업-프레임워크.md`](../동아리-CBL-수업-프레임워크.md): TRACES 6차시와 Act 기준

## 할 일

1. 교사별로 수업 주제 하나와 기준 원문보존본을 정한다.
2. [`../피드백-반영-기록지.md`](../피드백-반영-기록지.md)를 복사해 교사별 기록을 작성한다.
3. 각 항목을 `[사실]`, `[제안]`, `[확인]`으로 구분한다.
4. 성취기준, 학년, 수업 시간, 안전·개인정보 경계, 실제 또는 모의 Act 가능 범위를 교사와 확인한다.
5. 아직 확인되지 않은 항목을 다음 단계의 확정 수업안이나 HWPX 입력으로 넘기지 않는다.

## 완료 기준

- [ ] 교사별 수업 주제가 하나다.
- [ ] 기준 원문보존본 경로와 근거 위치를 기록했다.
- [ ] 유지·수정·확인 사항이 분리돼 있다.
- [ ] 수업의 실제 적용 또는 모의 적용 조건을 정했다.
- [ ] 다음 단계에서 풀어야 할 질문이 명확하다.
