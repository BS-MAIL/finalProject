## 3. 수학 공통 모델 검산 기준 [권고안]

원문의 공통 예시를 교사용 검산지에 유지한다.

- 공유기 A의 중심: `(4,3)`, 반지름: `6`
- 원의 방정식: `(x-4)²+(y-3)²=36`
- 점 P `(9,6)`: 거리 제곱은 `(9-4)²+(6-3)²=25+9=34<36`이므로 원 내부
- 점 Q `(12,3)`: 거리 제곱은 `(12-4)²+(3-3)²=64>36`이므로 원 외부
- 복도선 `y=3`은 중심을 지나므로 원과 두 점에서 만난다. 이 결론은 `y=3`을 원의 방정식에 대입하여 `(x-4)²=36`, 즉 `x=-2,10`으로도 확인한다.

교사용 검산지에는 다음을 함께 적는다.

1. 원의 방정식은 실제 전파의 물리 모형이 아니라 **가상 평면도에서 반지름을 일정하게 둔 수학 모형**이다.
2. 벽, 층, 사용 인원, 장비 성능, 실제 신호 세기는 반영하지 않는다.
3. 학생은 실제 공유기 위치·SSID·비밀번호·접속 기록·속도를 조사하거나 입력하지 않는다.
4. GeoGebra/Desmos는 그래프 확인 도구이며, 최종 판단은 식·거리 제곱·원과 직선의 위치 관계로 설명해야 한다.

## 5. 학생용·교사용 자료 제작 명세 [권고안]

### 5-1. 학생용 가상 평면도 활동지

| 면 | 학생이 해야 할 일 | 빈칸·조작 요소 | 넣지 말 것 |
|---:|---|---|---|
| 1 T/R | 우선 공간·단위·중심·반지름·한계를 정한다. | 우선순위 1~2, 변수 정의, 가상성 확인 | 실제 학교 지명·와이파이 정보 |
| 2 A | 원의 방정식, P/Q 거리 제곱, `y=3` 위치 관계를 계산한다. | 식 전개, 내부/위/외부 판단, 그래프 좌표 | 완성 정답·교사용 풀이 |
| 3 A/C | B/C 후보를 같은 기준으로 비교하고 판정 기준을 정한다. | 후보별 중심·반지름·커버 점·우선 공간 표 | “정답 후보” 표기 |
| 4 E/S | 후보 적용 결과, 기준 충족, 수정·유지 이유·한계를 기록한다. | 예측/결과/수정/한계 칸 | 실제 성능 향상 주장 |

### 5-2. 교사용 예시·오개념 메모

- P·Q의 거리 자체와 거리 **제곱** 비교를 혼동하는 경우
- 원 내부·원 위·원 외부 판단에서 부등호를 거꾸로 쓰는 경우
- 원과 직선의 위치 관계를 그림의 인상만으로 판단하는 경우
- 후보 B/C가 실제 공유기 설치 위치라는 오해
- 그래프 도구 결과만 붙이고 식·계산 근거를 쓰지 않는 경우
