# 교사별 TRACES 개선·반영 기록

> 상태: 원문보존본과 대조하여 작성한 **교사별 재구성 권고안**이다. 확정 수업안도 HWPX 입력본도 아니다.
>
> 표기: **[사실]**은 원문에서 직접 확인한 내용, **[개선]**은 원문의 결손·혼합을 구체화한 판단, **[추천]**은 해당 원문을 6차시로 옮길 때 권하는 활동·산출물·평가 설계, **[확인]**은 담당 교사가 결정해야 할 내용이다. `[추천]`과 `[확인]`은 확인 전 확정본에 옮기지 않는다.
>
> 공통 안전선: 발표는 Act가 아니다. E는 사전 승인된 저위험 실제 사용·시험 또는 원문 경계를 지키는 명시적 모의 적용이며, 외부 반응 수·실제 변화 크기·승인 여부는 평가하지 않는다.

## 읽는 법

각 원문에는 아래 네 가지를 남긴다.

1. **원문에서 살릴 것**: 이미 설계된 Challenge·수학 모델·자료 경계·평가 증거를 버리지 않는다.
2. **고칠 것**: 빈 차시, 한 차시에 섞인 판단, 모델과 결론의 단절을 정확히 지적한다.
3. **6차시 추천안**: 교사가 그대로 검토·수정할 수 있도록 차시별 학생 판단·교사 지원·산출물을 쓴다.
4. **확정 전에 답할 질문**: 추상적인 “확인 필요”가 아니라 수업 운영상 결정해야 할 선택을 적는다.

**기준 원문**: `원문보존/김규봉/함수와그래프_CBL_내주변현상_1차시.md`, `원문보존/김규봉/함수와그래프_CBL_내주변현상_2차시.md` — 연속 원문으로 함께 사용

**원문에서 살릴 것 [사실]**

- 제한된 면적을 `f(x)=A/x`, 한 변 길이를 `g(y)=sqrt(y)`, 합성을 `g(f(x))=sqrt(A/x)`로 연결하는 모델이 이미 있다.
- 학생이 생활 맥락을 선택하고, 변수·단위·정의역·치역을 정하며, 유리함수·무리함수·합성함수·역함수를 한 맥락에서 연결한다.
- 교사용 공통 모델 `A=3600 cm²`, `x∈{4,9,16,25,36}`과 사전 승인서가 준비돼 있어 자료의 안전한 출발점으로 쓸 수 있다.
- 원문은 AI 사용 시 검증·표시, 민감정보 미입력을 요구한다.

**무엇을 고쳐야 하나 [개선]**

- 현재 1차시는 모델 초안, 2차시는 그래프·역함수·발표까지 맡아 R(현실 조건 탐구), C(시험 계획), E(제한 시험), S(시험 결과에 따른 수정)가 사라진다.
- “실제 조건에 맞는 설계안”이라는 표현만 있고, 어떤 조건을 시험하고 어떤 계산 결과면 설계안을 바꿀지 정해져 있지 않다.
- 보고서·발표·갤러리워크는 공유·피드백이지 E가 아니다. ‘설계안을 써 봄’만으로는 제한 실행 증거가 되지 않는다.

**활동지·평가 추천 [추천]**

- 학생 활동지 1: `A`, `x`, 단위, 정의역, 현실 제약, “이 값은 왜 제외했는가?” 표
- 학생 활동지 2: `f`, `g`, `g∘f` 표·그래프와 후보 2개 비교, 역방향 질문
- 학생 활동지 3: 예측값/계산값/판단 기준/수정 여부를 한 칸에 기록하는 E-S 누적지
- 핵심 평가는 3개만 둔다: 함수 모델의 정확성, 제약을 반영한 후보 선택 근거, 시험 증거에 따른 수정 이유. 발표 완성도나 실제 적용 규모는 점수화하지 않는다.

**교사가 확정할 사항 [확인]**

1. E는 전원 공통 모델로 할지, 사전 승인된 비민감 생활 맥락까지 허용할지
