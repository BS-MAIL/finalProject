# 원문별 TRACES 피드백·반영 기록지

> 상태: 원문 대조를 끝낸 재구성 피드백 기록지. 이 문서는 확정 수업안이 아니며, 원문보존본을 바꾸지 않는다.
>
> 표기: **[사실]**은 원문에 직접 있는 내용, **[제안]**은 TRACES 6차시로 재구성할 때의 보완안, **[확인]**은 교사가 결정해야 할 사항이다. 제안·확인 항목은 교사 확인 전 HWP/HWPX 확정본에 옮기지 않는다.
>
> 공통 원칙: TRACES는 CBL을 대체하는 이론이 아니라 동아리용 실행 틀이다. `T 문제 포착·도전 정식화 → R 질문 기반 탐구 → A 수학적 해결안 설계 → C 실행 계획 → E 제한 실행 → S 실행 증거 해석·수정·성찰`의 6차시를 기본으로 한다.

## 1. 판정 기준

| 항목 | 기록 방법 |
|---|---|
| T/R/A/C/E/S | 원문에 이미 있는 단계는 `[사실]`, 새로 나누거나 더할 단계는 `[제안]`으로 적는다. |
| Act | 발표·제안서·검토만으로 Act로 판단하지 않는다. 실제 또는 안전한 맥락에서 사용·제한 시험한 증거가 있을 때만 E로 기록한다. |
| 모의 적용 | 실제 적용이 **안전·개인정보·수업 운영·승인·시간 조건을 충족하지 못해 불가하거나 부적절한 경우에만** 가상·역할 기반·공개 자료 적용으로 전환한다. 실제 변화나 실제 수요자 반응으로 표기하지 않는다. 원문이 실제 관찰·개입을 금지하면 그 원문 경계를 우선한다. |
| AI | 원문에 AI가 없으면 `AI 미사용`이 가능하다. 사용한 차시에는 목적·입력 경계·검증·비식별 요약·반영 이유를 확인한다. |
| 평가 | 외부 협력 승인, 실제 변화 규모, 실제 수요자 반응 수는 평가하지 않는다. 수학적 근거·제약 분석·실행 설계·증거 해석·수정 이유를 본다. |

## 2. 원문별 피드백

### GYB-01 + GYB-02 — 김규봉 / 함수와그래프_CBL_내주변현상_1·2차시 연속 원문

- **원문 근거 [사실]**: `원문보존/김규봉/함수와그래프_CBL_내주변현상_1차시.md` 원문 1~3쪽과 `원문보존/김규봉/함수와그래프_CBL_내주변현상_2차시.md` 원문 1~3쪽은 같은 프로젝트의 연속 차시다. 1차시 원문은 제한된 면적을 `f(x)=A/x`, `g(y)=√y`, `g∘f`로 모델링하고 생활 맥락을 선택하게 하며, 2차시 원문은 무리함수·역함수 탐구와 최종 선택·공유를 담당한다. 두 원문 차시표의 4~10차시는 비어 있다.
- **현재 진단 [사실]**: T의 생활 맥락 선택과 A의 함수 모델은 있으나, R의 질문·자료 근거, C의 실행 계획, E의 제한 실행, S의 실행 증거 해석이 차시로 분리되어 있지 않다. 보고서·발표는 E가 아니라 공유 산출물이다.
- **TRACES 재구성 [제안]**: 1T 생활 맥락·정의역 승인 → 2R 변수·단위·현실 제약·자료 출처표 → 3A GYB-01의 `f,g,g∘f`와 GYB-02의 무리함수·역함수·최종 선택 근거를 연결해 해결안 후보 비교 → 4C 교사 승인 범위의 비민감 실제 조건 또는 교사 제공 공통 모델에서 시험할 기준·기록 방식 계획 → 5E 그 실제 조건 또는 공통 모델에 설계안을 제한 적용해 계산·그래프·역방향 해석을 비교 → 6S 모델 예측과 계산 결과 비교, 정의역·가정 수정, 개인 성찰로 구성한다. 실제 환경의 변경·구매·설치는 하지 않는다.
- **안전·AI [사실/제안]**: 원문 3쪽은 AI 사용 시 검증·표시와 민감정보 비입력을 요구한다. [제안] AI는 질문 다듬기·검산이 필요한 차시에만 사용하고, 생활 공간의 실제 주소·사진·개인 자료는 입력하지 않는다.
- **교사 확인 [확인]**: 두 원문은 1·2차시 연속 자료로 함께 유지한다. 교사는 승인 가능한 비민감 실제 조건의 범위와, 공통 모델로 대체해야 하는 경우를 확정한다.

### GYB-03 — 김규봉 / 도형의방정식_CBL_안전한학교_1-2차시_통합 [참고 초안·기준 원문 미확정]

- **원문 근거 [사실]**: `원문보존/김규봉/참고-초안/archive/안전한학교_과거안/최종산출물/도형의방정식_CBL_안전한학교_1-2차시_통합.md` 원문 1~2쪽은 익명화한 학교 약식 지도로 안전 사각지대 후보를 모델링하고 개선안을 공유하는 Challenge를 둔다. 원문 3~4쪽은 정확한 내부 평면도·개인정보의 AI 입력 금지, 실제 설치·운영 판단은 안전 담당자 검토가 필요하다고 명시한다. 차시표는 1~2차시만 채워져 있다.
- **현재 진단 [사실]**: T와 A는 강하나, 2차시의 ‘분석·실행·공유’는 제한 실행, 발표, 성찰을 한 차시에 혼합한다. 실제 시설 변경은 원문도 요구하지 않는다.
- **TRACES 재구성 [제안]**: 1T 안전을 판단하는 수학적 질문·가상 지도 범위 → 2R 좌표·축척·거리·안전 기준의 자료 한계 → 3A 원·직선 모델과 개선 후보 비교 → 4C 가상 지도에서의 제한 시험 기준·중단 조건 → 5E 익명 약식 지도에서 후보 배치의 접근 범위를 제한 시험 → 6S 실제 안전 판정이 아닌 모델 결과임을 밝히며 수정·성찰한다.
- **안전·AI [사실/제안]**: 실제 내부 구조·개인정보·출입 제한 정보 비입력과 AI 교차검증은 원문 3쪽 근거를 유지한다. [제안] E는 가상 약식 지도만 사용하며 시설물 이동 또는 현장 안전 판정으로 확대하지 않는다.
- **교사 확인 [확인]**: archive 참고 초안을 채택하기 전에는 확정 기준 원문 수에 포함하지 않는다. 채택 여부와 적용 학년·성취기준을 교사가 결정한다.

### GKH-01 — 구교희 / 고2미적분1_학교밀집도_CBL_1-2차시_통합

- **원문 근거 [사실]**: `원문보존/구교희/고2미적분1_학교밀집도_CBL_1-2차시_통합.md` 원문 1~2쪽은 익명화한 급식실·복도 밀집도 자료와 교사 제공 함수 모델로 입장 간격 정책을 제안한다. 원문 3~4쪽에는 변화량·평균변화율·그래프와 후보 간격 비교·발표가 1~2차시에 압축되어 있다. 원문 1쪽은 개인정보 배제와 AI·모델 한계 검증을 가치로 둔다.
- **현재 진단 [사실]**: 2차시 안에 T/R/A/제안/공유가 압축되어 있고 E의 실제 또는 제한 실행은 없다. 원문에서 실제 학생 동선 관찰이나 정책 시행을 근거로 확인할 수 없다.
- **TRACES 재구성 [제안]**: 1T 가상 안전·운영 문제와 Challenge → 2R 익명 자료의 단위·조건·누락, Guiding Questions → 3A 변화율·도함수·후보 간격 모델 비교 → 4C 교실 내 가상 대기선 또는 시뮬레이션 시험 계획 → 5E 교사 제공 가상 시나리오에서 후보 간격을 제한 시험 → 6S 수학적 결과·한계·반대안·수정 이유를 정리한다.
- **안전·AI [사실/제안]**: 원문은 익명 자료를 전제한다. [제안] 실제 급식 운영·학생 동선·사진 수집은 하지 않고, 모의 적용은 실제 안전 판정이 아님을 표시한다.
- **교사 확인 [확인]**: GKH-01과 GKH-02는 중복 후보가 아니라 각각 다른 성취기준·수학적 모델을 가진 별도 원문으로 유지한다. 적용 학년·교육과정 기준과 어느 원문을 실제 수업에 사용할지를 확인한다.

### GKH-02 — 구교희 / 고2미적Ⅰ_학교밀집도_CBL_대표7차시

- **원문 근거 [사실]**: `원문보존/구교희/고2미적Ⅰ_학교밀집도_CBL_대표7차시.md` 원문 1~4쪽은 교사 제공 가상 자료·80명 가상 기준·실제 관찰 금지·개인정보 보호를 명시한다. 원문 3~4쪽 차시표는 Engage, 공간 선택, 자료 확인, 변화율·그래프·도함수, 후보 비교, 제안서, 발표·수정, 성찰의 10차시를 제시한다.
- **현재 진단 [사실]**: T/R/A/S가 원문에 비교적 명료하고, 8차시는 제안서 정리여서 C에 가깝다. 그러나 실제 또는 제한 실행은 명시되지 않아 8차시 Act를 E로 읽을 수 없다.
- **TRACES 재구성 [제안]**: 기존 1~7차시의 자료·미분 모델 활동을 T/R/A로 묶고, 8차시의 반대안·한계 정리를 C로 둔다. 9차시 전 또는 별도 차시에 교사 제공 가상 시나리오에서 후보 간격·유휴시간을 제한 시험하는 E를 넣고, 10차시 성찰을 S로 유지한다. 원문이 10차시이므로 6차시로 축소할 때는 R/A 내부 활동을 통합하되 E를 삭제하지 않는다.
- **안전·AI [사실/제안]**: 원문 3쪽은 익명 자료만, 학생 관찰·촬영 없이, AI는 확인용으로 쓰도록 한다. [제안] 80명은 공식 기준이나 실제 정책 결과로 쓰지 않고 교실용 가상 기준으로 표시한다.
- **교사 확인 [확인]**: 가상 시나리오 E를 원문 범위에서 허용할지, 10차시 전체를 유지할지 결정한다.

### GKH-03 — 구교희 / 고2대수_신호대기주기_CBL_대표7차시

- **원문 근거 [사실]**: `원문보존/구교희/고2대수_신호대기주기_CBL_대표7차시.md` 원문 1~4쪽은 교사 제공 모의 자료·90초 가상 기준, 실제 교통 관찰·도로 개입·사진 촬영 금지, 실제 교통 정책 조언이 아님을 명시한다. 원문 3~4쪽은 1~10차시로 Engage, 삼각함수 모델, 비교·제안, 발표·수정, 윤리 성찰을 제시한다.
- **현재 진단 [사실]**: T/R/A와 S는 충분하다. 7차시 모델 작성과 8차시 대안 비교는 A에 해당하고, 9차시 발표·질문·수정은 피드백이다. 실제 도로 적용은 원문이 명시적으로 금지하므로 E는 모의 적용이어야 한다.
- **TRACES 재구성 [제안]**: 1T 모의 문제·안전 경계 → 2R 시간·단위·주기 자료와 질문 → 3A 기준선 `W(t)`와 대안 `W_a(t)`의 주기·범위·최대 대기시간을 비교해 선택 근거를 설계 → 4C 90초 가상 기준에서 비교할 최대 대기·한계·기록 방식 계획 → 5E 교사 제공 모의 신호표에서 두 대안을 제한 실행·표본값 확인 → 6S 판단 기준 대비 결과·모델 한계·수정 이유를 성찰한다. 코사인·탄젠트는 그래프 성질 검토와 대기시간 모델의 비적합성 설명에 한정한다.
- **안전·AI [사실/제안]**: 원문 3쪽은 개인정보 비입력, AI 로그, 손계산·표본 대입 검증을 요구한다. [제안] E의 결과는 교통 정책 추천이나 실제 관찰 결과로 표현하지 않는다.
- **교사 확인 [확인]**: GKH-03과 `추가-산출물`의 동명 문서는 중복 여부를 확인하고 기준 원문을 하나로 정한다.

### LSH-01 — 이승희 / 중1_대푯값_CBL_이승희_1-2차시_통합

- **원문 근거 [사실]**: `원문보존/이승희/중1_대푯값_CBL_이승희_1-2차시_통합.md` 원문 1~4쪽은 극단값이 있는 가상 용돈 자료로 대푯값 선택 기준을 탐구하고, 비민감 생활 자료와 앱 결과를 원자료로 검증해 생활 제안을 공유한다. 실제 가정 형편을 묻지 않는다는 경계가 원문에 있다.
- **현재 진단 [사실]**: 1~2차시에 T/R/A/S가 압축돼 있으며 앱 입력·검증은 도구 확인에 가깝다. 원문만으로는 해결안을 실제 사용·제한 시험한 E가 명확하지 않다.
