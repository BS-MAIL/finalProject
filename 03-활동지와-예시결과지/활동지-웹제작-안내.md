# 학생 활동지와 예시 활동지를 웹으로 제작하는 안내

> 대상: OpenCode, Pi.dev, Hermes 같은 바이브코딩 도구를 처음 쓰거나, 활동지를 HTML로 만들어 HWPX에 이미지·PDF로 넣어야 하는 MAIL 동아리 구성원
>
> 목표: 수업의 판단과 기록에 실제로 쓰이는 활동지 한 장을 설계하고, A4에 맞는 HTML로 만든 뒤 PDF 또는 PNG로 내보내 HWPX 제작 담당자에게 안전하게 전달한다.

## 먼저 기억할 원칙

웹 활동지는 “보기 좋은 홍보물”이 아니라 학생이 **무엇을 보고, 무엇을 판단하고, 무엇을 남길지**를 돕는 수업 도구다. 디자인이나 AI는 그 판단을 더 잘 보이게 하는 보조 수단이다.

- 한 활동지는 한 차시의 핵심 판단 하나를 돕는다. 예: “어떤 변수를 조사할까?”, “어떤 해결안이 더 타당한가?”, “시험 결과 뒤 무엇을 수정할까?”
- 정답·결론을 활동지에 먼저 넣지 않는다. 학생의 표, 계산, 근거, 수정 이유를 쓸 자리를 남긴다.
- 활동지에 실명, 학번, 얼굴, 연락처, 교직원·시설의 비공개 정보, 식별 가능한 사진을 넣지 않는다.
- AI가 만든 문장·그래프·통계·출처는 초안일 뿐이다. 교사 또는 담당 학생이 수학적 정확성, 단위, 실제 사용 가능성, 저작권·라이선스를 확인한다.
- 이 저장소에는 확정 Markdown과 제작·검증 기록만 둔다. HTML, PDF, PNG, 폰트, 이미지 원본은 HWPX 제작 담당자의 별도 작업 폴더에 둔다.

## 1. 활동지에 필요한 구성요소를 정하는 법

### 1-1. 활동지를 만들기 전에 네 문장으로 설계한다

코드를 시작하기 전에 아래 네 문장을 수업안 또는 제작 메모에 먼저 쓴다.

| 질문 | 작성 예시 |
|---|---|
| 이 활동지가 쓰이는 차시는? | 3차시 A - Architect |
| 학생이 끝에 할 판단은? | 세 해결안 중 무엇을 선택할지 식·그래프·제약 조건으로 정당화한다. |
| 학생이 남길 증거는? | 변수표, 계산·그래프, 후보 비교표, 선택 이유 두 문장 |
| 교사가 확인할 것은? | 단위·가정·계산이 맞는지, 선택 근거가 표의 기준과 연결되는지 |

이 네 문장에 답하지 못하면 디자인을 고르기 전에 활동 목표를 더 좁힌다. 한 장에 여러 판단을 넣으면 학생은 채우기만 하고 무엇을 배웠는지 드러내기 어렵다.

### 1-2. TRACES 단계별 최소 구성

아래는 “반드시 이 모양이어야 한다”는 서식이 아니라, 각 단계에서 판단을 남기기 위한 최소 요소다.

| 단계 | 활동지 핵심 요소 | 학생이 빈칸에 남길 것 |
|---|---|---|
| T - Trigger | 상황·자료 출처, 문제 관찰, Big Idea, Essential Question, Challenge 초안 | 문제의 모습, 중요 이유, 도전 문장 |
| R - Research | Guiding Questions, 자료 출처, 변수·단위·범위 표, 신뢰도·한계 확인 | 조사 질문, 자료, 변수 뜻, 빠진 정보 |
| A - Architect | 모델·계산·그래프 영역, 가정, 해결안 후보 비교 기준 | 식·표·그래프, 가정, 후보별 장단점과 선택 근거 |
| C - Change-plan | 대상·맥락, 실행물, 판단 기준, 안전·중단 조건, 대체안 | 무엇을 어디에서 어떻게 시험할지 |
| E - Execute | 실행 전 체크, 관찰·피드백 표, 변경·중단 기록 | 실제 또는 모의 실행 기록과 관찰값 |
| S - Study | 판단 기준 대비 결과, 수정 전후 비교, 한계, 개인 성찰 | 유지·수정 이유와 다음 제안 |

### 1-3. A4 한 장의 정보 구조

A4 한 장에는 다음 순서가 안정적이다.

1. **머리 영역**: 활동지 제목, 차시·단계, 소요 시간, 오늘의 목표 한 문장
2. **상황·자료 영역**: 꼭 필요한 맥락, 출처, 조건. 긴 설명은 수업안이나 교사 설명으로 보낸다.
3. **학생 작업 영역**: 표, 계산 칸, 그래프 칸, 비교 기준처럼 학생이 직접 쓰거나 표시하는 부분
4. **판단·근거 영역**: “우리는 ___을 선택한다. 근거는 ___이다.”처럼 결론과 근거를 연결하는 문장 틀
5. **점검 영역**: 단위·가정·출처·안전 또는 AI 사용 여부를 짧게 확인

활동지의 빈칸은 장식이 아니다. 각 빈칸은 교사가 나중에 확인할 학습 증거와 연결해야 한다. 그래프가 필요한 활동지라면 축 이름, 단위, 범위, 눈금의 의미를 먼저 정하고 학생이 그래프를 만들거나 해석할 충분한 공간을 준다.

### 1-4. 예시 활동지는 답안지가 아니다

예시 활동지는 학생에게 “완성본을 베끼게” 하는 자료가 아니라, 활동 방법과 품질 기준을 보여 주는 자료다.

- 학생용 활동지와 예시 활동지를 파일명·머리말에서 명확히 구분한다.
- 예시는 같은 양식에 가상의 저위험 자료를 사용한다.
- 예시에 계산 과정, 가정, 한계, 선택 근거를 보이되 학생 과제의 정답을 선공개하지 않는다.
- 학생용에는 빈 작업 칸을 남기고, 교사용 예시에는 왜 이 근거가 충분한지 짧은 주석을 붙인다.

## 2. 활동지를 HTML로 만드는 가장 쉬운 방법

### 2-1. 작업 폴더를 먼저 분리한다

HTML과 내보낸 PDF·이미지는 이 Git 저장소 밖의 별도 작업 폴더에 둔다. 예를 들면 다음과 같다.

```text
활동지-작업/
  01-설계메모.md
  02-학생용-활동지.html
  03-교사용-예시.html
  export/
    학생용-활동지.pdf
    학생용-활동지.png
```

확정 수업안 Markdown에는 이 파일을 만들었다는 사실과 HWPX에 넣을 최종 파일명·버전만 기록한다. 원본 HTML과 이미지 파일 자체를 이 저장소에 커밋하지 않는다.

### 2-2. 도구에게 시킬 일과 사람이 결정할 일을 구분한다

OpenCode, Pi.dev, Hermes에 바로 “예쁜 활동지 만들어 줘”라고만 요청하면 수업 목표와 맞지 않는 포스터가 나오기 쉽다. 아래 정보를 먼저 적어 주고, 도구에는 HTML 제작과 수정만 맡긴다.

| 사람이 먼저 정할 것 | 도구에 요청할 수 있는 것 |
|---|---|
| 차시, 학생의 핵심 판단, 성취기준, 수학 내용 | A4 CSS와 표·입력 칸의 HTML 구현 |
| 사용할 사실·수치·자료 출처와 단위 | 가독성 있는 배치, 인쇄용 스타일, 반응형 미리보기 |
| 학생용/교사용 구분, 정답 공개 범위 | 예시 데이터를 넣은 교사용 버전 복제 |
| 개인정보·안전 경계 | HTML 문법 검사, PDF·PNG 내보내기 스크립트 제안 |

### 2-3. 처음 요청할 때 쓸 프롬프트

아래 대괄호만 자신의 수업 내용으로 바꾸어 OpenCode, Pi.dev, Hermes에 보낸다. 사실·수치·정답은 검증한 내용만 넣는다.

```text
당신은 수업용 인쇄물 HTML을 만드는 보조자다.
외부 이미지, 외부 폰트, CDN, 추적 스크립트를 쓰지 말고 하나의 self-contained HTML 파일만 만들어라.

대상: [학년/과목]
차시와 TRACES 단계: [예: 3차시, A - Architect]
오늘 학생이 할 핵심 판단: [한 문장]
학생이 남길 증거: [표/식/그래프/비교표/근거 문장]
필수 수학 내용: [변수, 단위, 식, 자료 출처]
금지할 내용: [실명, 실제 학생 자료, 정답 선공개 등]

인쇄 규격:
- A4 세로 1쪽, 여백 12 mm, 12pt 이상 본문 글자
- 브라우저에서 인쇄할 때 페이지가 잘리지 않게 @page와 @media print를 포함
- 색 없이 인쇄해도 표와 구역이 구분되게 테두리·명도·제목 계층 사용
- 학생이 손으로 쓸 빈칸과 그래프/계산 공간을 충분히 확보
- 학생용 버전이며 해답은 넣지 않음

완성 후 다음을 함께 제시하라.
1) 만든 HTML 전체
2) A4 1쪽을 넘길 위험이 있는 영역
3) 교사가 사실·수학·저작권 측면에서 확인할 목록
```

교사용 예시가 필요할 때는 같은 HTML을 복사한 다음, 다음처럼 한정해서 요청한다.

```text
이 학생용 활동지의 구조와 디자인은 유지하되 교사용 예시 버전을 만들어라.
가상의 안전한 예시 자료를 사용하고, 학생용 과제의 실제 정답을 공개하지 마라.
각 예시 답에는 계산·단위·가정·한계를 짧게 표시하라.
머리말에 반드시 '교사용 예시 - 학생 배부 전 검토용'을 넣어라.
```

### 2-4. HTML에서 꼭 들어가야 할 인쇄 설정

도구가 만든 파일에는 최소한 아래와 같은 인쇄 설정이 있는지 확인한다. 이것은 디자인을 복사하기 위한 코드가 아니라 A4 크기와 인쇄 안전 영역을 정하는 기본 설정이다.

```html
<style>
  @page { size: A4 portrait; margin: 12mm; }
  * { box-sizing: border-box; }
  body { margin: 0; font-family: sans-serif; color: #1f2933; }
  .sheet { width: 186mm; min-height: 273mm; margin: 0 auto; }
  .write-space { min-height: 28mm; border: 1px solid #4b5563; }
  table { width: 100%; border-collapse: collapse; }
  th, td { border: 1px solid #4b5563; padding: 2.5mm; vertical-align: top; }
  @media print {
    body { background: #fff; }
    .no-print { display: none !important; }
    .sheet { width: auto; min-height: auto; }
  }
</style>
```

- 화면 폭이 아니라 `mm`로 용지 크기와 여백을 잡는다.
- `12pt`보다 작은 본문 글씨, 너무 연한 회색, 색으로만 구분한 표시는 피한다.
- 한 페이지에 억지로 넣기 위해 글씨를 줄이지 않는다. 필요한 경우 활동지를 2쪽으로 나누고 수업안에 그 사실을 명시한다.
- PDF로 뽑기 전에 브라우저 인쇄 미리보기에서 표가 페이지 중간에서 잘리지 않는지, 수식과 그래프가 겹치지 않는지 확인한다.

## 3. 원하는 디자인을 찾고 요청하는 법

### 3-1. 참고 자료를 찾을 곳

다른 사람의 문서를 그대로 복제하지 말고, **정보 구조와 읽기 방식**을 참고한다. 사진, 삽화, 아이콘, 유료 템플릿, 폰트는 각각 이용 조건을 확인한다.

| 찾는 목적 | 참고할 곳 | 검색어 예시 |
|---|---|---|
| 인쇄물·워크시트의 정보 구조 | [Canva 교육 템플릿](https://www.canva.com/education/), [Adobe Express 교육 템플릿](https://www.adobe.com/express/templates/education) | `math worksheet`, `student reflection worksheet`, `project planning worksheet` |
| 표·카드·문서 레이아웃 참고 | [Figma Community](https://www.figma.com/community) | `worksheet`, `education workbook`, `a4 document layout` |
| 프레젠테이션·문서 톤 참고 | [Slidesgo](https://slidesgo.com/), 학교·교육기관 공개 자료 | `classroom worksheet`, `learning journal`, `project planner` |
| 공공·교육 자료의 실제 문서 형식 참고 | 교육청·공공기관의 공개 PDF | `[과목] 활동지 filetype:pdf`, `[주제] 학습지 filetype:pdf` |

참고한 URL, 사용한 이미지·아이콘의 출처와 이용 조건은 활동지 작업 메모에 남긴다. 학교·교실 사진, 학생 작품, 다른 출판물의 그림을 검색해서 무단으로 넣지 않는다.

### 3-2. 검색할 때 보는 기준

마음에 드는 화면을 찾았더라도 다음을 먼저 확인한다.

- 제목, 안내, 학생 작업, 점검의 순서가 분명한가?
- 흑백 인쇄에서도 표와 영역이 구분되는가?
- 학생이 직접 쓸 공간이 충분한가?
- 장식이 수식·그래프·표를 가리거나 인쇄 면적을 빼앗지 않는가?
- 학생의 실제 판단과 무관한 “예쁜 카드”가 반복되지는 않는가?
- 이미지·폰트·템플릿을 재사용할 권한이 있는가?

### 3-3. 참고 이미지를 받은 뒤 도구에 요청하는 법

도구에는 “이 디자인을 똑같이 복제해 달라”고 하지 않는다. 특정 브랜드나 제작자의 고유 레이아웃·삽화·문구를 베끼지 않고, 필요한 원칙만 추출하도록 요청한다.

```text
첨부한 참고 자료에서 그대로 복제하지 말고 다음 원칙만 추출해 활동지에 적용해라.
- [예: 제목과 작업 영역의 대비]
- [예: 표의 행 간격과 쓰기 공간]
- [예: 두 단계 정보를 구분하는 방식]

고유한 로고, 그림, 문구, 색 체계, 카드 배치는 사용하지 말고,
A4 학생 활동지에 맞는 새로운 HTML 레이아웃을 만들어라.
학생의 핵심 판단은 [판단]이고, 반드시 [산출물]을 직접 작성할 공간을 남겨라.
```

## 4. HTML을 PDF 또는 PNG로 내보내는 법

### 4-1. 가장 쉬운 방법: 브라우저 인쇄

1. HTML 파일을 Chrome 또는 Edge로 연다.
2. 화면에서 글자·표·그래프·빈칸을 확인한다.
3. `Ctrl+P` 또는 인쇄 메뉴를 연다.
4. 대상에서 **PDF로 저장**을 선택한다.
5. 용지는 A4, 방향은 활동지 설정과 동일하게 선택한다.
6. 배율은 기본값부터 확인한다. `한 페이지에 맞추기` 때문에 글씨가 지나치게 작아지면 HTML을 고친다.
7. 머리글·바닥글은 끈다. 배경 그래픽은 색상 구분이 꼭 필요할 때만 켠다.
8. 저장한 PDF를 다시 열어 페이지 수, 잘린 표, 글자 겹침, 수식·그래프 선명도를 확인한다.

### 4-2. 반복 제작할 때: Chrome 명령으로 PDF와 PNG 만들기

이 컴퓨터에는 `google-chrome` 명령이 설치되어 있다. 아래 명령은 HTML 파일을 직접 열어 PDF와 PNG를 만드는 방식이다. 경로의 공백을 피하려면 파일명과 폴더명을 간단히 정한다.

```bash
# HTML을 A4 PDF로 저장한다. HTML의 @page, @media print 설정을 먼저 확인한다.
google-chrome --headless --disable-gpu \
  --print-to-pdf="/작업폴더/export/학생용-활동지.pdf" \
  "file:///작업폴더/02-학생용-활동지.html"

# 화면용 PNG 미리보기. PDF의 정확한 인쇄 검수는 위 PDF를 기준으로 한다.
google-chrome --headless --disable-gpu --window-size=1240,1754 \
  --screenshot="/작업폴더/export/학생용-활동지-미리보기.png" \
  "file:///작업폴더/02-학생용-활동지.html"
```

- PNG는 HWPX에 그림으로 넣기 편하지만, 여러 쪽 활동지를 한 장의 긴 화면 캡처로 만들지 않는다. 쪽별 PNG가 필요하면 PDF를 쪽별 이미지로 변환하거나 활동지를 쪽별 HTML로 나눈다.
- PDF는 인쇄 품질과 쪽 구성이 유지되므로 검수 기준으로 우선 사용한다.
- PDF·PNG를 만든 뒤 반드시 열어 본다. 명령이 성공해도 표가 잘리거나 글꼴이 바뀔 수 있다.

### 4-3. HWPX에 넘기기 전 인수 목록

HWPX 제작 담당자에게 아래 정보를 함께 전달한다.

- 확정 수업안 Markdown 경로와 차시·산출물 이름
- 학생용/교사용 예시 구분
- 최종 PDF 또는 PNG 파일명, 쪽 수, 버전, 생성 일시
- 삽입할 HWPX의 위치: 예) `3차시 학생 활동지 뒤`, `교사용 예시 부록 2쪽`
- 원본 HTML과 PDF·PNG가 있는 별도 작업 경로
- 사람이 확인한 내용: 수학·수치·출처·개인정보·저작권·인쇄 상태

HWPX에 삽입한 뒤에는 HWPX를 다시 열고, 표·수식·이미지·쪽 구성이 원래 의도와 같은지 확인한다. 최종 검증 결과는 이 저장소의 `templates/HWPX-검증-보고서.md` 형식으로만 남긴다.
