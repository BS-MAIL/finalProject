# 3단계: 활동지와 예시 결과지 제작

## 목적

확정 수업안의 각 차시에서 학생이 남겨야 하는 증거를 학생용 활동지와 교사용 예시 결과지로 만든다. 활동지는 HTML로 설계하고 PDF 또는 PNG로 내보내 HWPX 제작 입력으로 준비한다.

## 안내문과 작업 위치

- 자세한 제작 안내: [`../활동지-웹제작-안내.md`](../활동지-웹제작-안내.md)
- HTML, PDF, PNG, 이미지 원본은 **이 저장소 밖 별도 작업 폴더**에 둔다.
- 이 폴더에는 활동지 원본을 넣지 않는다. 필요한 경우 활동지 목록·버전·삽입 위치를 적은 Markdown 기록만 둔다.

## 작업 순서

1. 차시별로 학생이 해야 할 핵심 판단과 남길 증거를 한 문장으로 정한다.
2. 머리 영역, 상황·자료, 학생 작업 영역, 판단·근거, 점검 영역을 배치한다.
3. OpenCode, Pi.dev, Hermes 등으로 A4 HTML 초안을 만든다. 도구에는 차시·판단·수학 내용·금지 정보·인쇄 규격을 명확히 준다.
4. 학생용 활동지에는 빈 작업 칸을 남기고 정답을 넣지 않는다.
5. 교사용 예시 결과지에는 가상의 안전한 자료와 계산·가정·한계를 표시하고, 학생용과 구분한다.
6. 브라우저 인쇄 또는 Chrome headless로 PDF와 PNG를 만든다.
7. PDF를 열어 표 잘림, 수식·그래프 겹침, 글자 크기, 흑백 가독성을 확인한다.
8. HWPX 생성 요청서에 활동지 파일명, 학생용/교사용 구분, 버전, 삽입 위치를 기록한다.

## 완료 기준

- [ ] 활동지가 차시의 핵심 판단 하나를 돕는다.
- [ ] 학생이 직접 쓸 표·계산·그래프·근거 공간이 있다.
- [ ] 수치·단위·수식·출처·이미지 이용 조건을 사람이 검토했다.
- [ ] 개인정보·비공개 학교 정보·정답 선공개가 없다.
- [ ] PDF 또는 PNG를 실제로 열어 인쇄 상태를 확인했다.
- [ ] HWPX에 넣을 파일명·버전·삽입 위치가 생성 요청서에 기록돼 있다.
