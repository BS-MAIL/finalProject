# HWPX 생성 요청서

## 생성 금지 사항

- [ ] 원문 근거가 없는 내용을 추가하지 않는다.
- [ ] `교사 확인 필요`, `재구성 제안`, 빈 대괄호를 포함하지 않는다.
- [ ] 양식의 표 구조·수식 영역을 임의 변경하지 않는다.
- [ ] HWPX 결과물을 이 저장소에 넣지 않는다.

## 인수 확인

- [ ] 확정 수업안의 총 차시와 생성 대상 차시가 일치한다.
- [ ] 확정 수업안이 한 주제의 기본 6차시 TRACES 수업지도안이며, 차시별 중간 산출물과 최종 성과물이 연결돼 있다.
- [ ] Challenge·학생 주도 선택·Act 피드백 및 수정이 구체적으로 확정돼 있다.
- [ ] 성취기준·안전 경계·A0~A4·예상 산출물이 모두 입력돼 있다.
- [ ] 검증 담당자에게 전달할 파일명·SHA-256·생성 도구·양식 버전을 기록할 준비가 됐다.
