# 산포도 3차시 인쇄 자료

교사는 전체 안내인 `index.html`, 학생은 학생 전용 목차인 `students.html`을 브라우저로 여세요. 외부 자산·접속·설치 없이 작동합니다. 학생용과 교사용은 별도 파일이며 학생 파일에 답안이나 예시 데이터 스크립트를 넣지 않았습니다. 인쇄 버튼에만 선택적으로 JS를 사용합니다. JS를 끄면 Ctrl+P로 인쇄합니다.

## 학생용 배포 범위

학생에게는 `students.html`, `student-01.html`, `student-02.html`, `student-03.html`, `style.css`, `print.js`만 같은 폴더 구조로 전달하세요. `teacher*.html`, `sample-data.js`, `index.html`, 이 README를 포함한 교사용 안내는 제외합니다. 학생 목차와 학생 활동지의 링크는 학생 파일과 공유 CSS/JS 안에서만 이어집니다.

이는 탐색 동선과 배포 파일의 분리이지 **정적 URL 접근을 보안상 차단하는 기능이 아닙니다**. 교사용 파일을 같은 공개 서버에 올리면 주소를 아는 사람이 직접 접근할 수 있습니다. 답안 비공개가 필요하면 학생 배포 위치에는 위 여섯 파일만 두고 교사용 자료는 별도 비공개 위치에서 관리하세요.

## 파일과 쪽 구성

| 학생용 | 같은 양식의 교사용 | A4 세로 의도 쪽 수 |

| student-02.html | teacher-02.html | 각각 4쪽: 선기준 / A–C 분석 / D–E·한계 / 독립 한 장 제안서 |

공통 파일: `style.css`, `print.js`. `index.html`은 화면 탐색용입니다. 빈 작업 칸은 종이에 손으로 쓰는 방식이며 입력 폼이 아닙니다. 내용 자르기·고정 높이·숨김 없이 최소 높이만 사용하므로 내용을 수정해 길어지면 인쇄 쪽이 늘어날 수 있습니다. 한 장 제안서는 간결한 문장으로 작성하세요.

## 수업과 인쇄

- 기준: `02-TRACES-수업안-확정/이승희_산포도-3차시-수업지도안-수정안.md`. 완성된 학급 통계·평가·의견·추천 앱이 제공된다는 수업 전제이며 여기서는 앱을 개발하거나 작동을 검증하지 않습니다.
- A4 세로, CSS 여백 12mm, 배율 100%, 브라우저 머리글·바닥글 끄기. 파일 전체를 인쇄하거나 2차시 4쪽만 선택하면 독립 제안서입니다. 모둠 6개 기준 제안서는 모둠당 한 장, 수집·전후 기록은 개인용입니다.
- 본문 12pt, 인쇄 보조 안내 9.5pt, 표 10~11pt, 제안서의 간결한 예시·안내 10pt. 로컬 한글 글꼴(맑은 고딕/Apple SD Gothic Neo 등)을 사용하므로 컴퓨터별 줄바꿈은 인쇄 미리보기에서 확인하세요.
- 1차시 안전 시범 때 교사가 도구·거리·성공 판정 세부를 동일하게 확정해 안내합니다. 앱 평가 척도도 확인합니다. 사진은 필수가 아니며 필요하면 교사가 도구 배치만 촬영합니다.
- 기본 안전은 거래할 점수가 아닙니다. 수행하지 않아도 대체 역할로 참여하며 건강정보를 공개하지 않습니다. 실제 누락은 0이 아닌 빈칸으로 처리하고 n의 한계를 명시합니다.

## 가상 원자료의 재현

`sample-data.js`는 익명 가상 30행(`raw`), 종목별 기록과 4요소 개별 평가, 각 종목의 예시 익명 의견을 제공합니다. 5값 패턴을 6회 반복한 설명용 자료입니다. 실제 수업 결과가 아닙니다. `node -e "console.log(JSON.stringify(require('./public/이승희-산포도-3차시/sample-data.js'),null,2))"`로 원자료와 집계를 재현할 수 있습니다. 출력은 저장할 필요가 없습니다.

모든 종목 유효 기록 30개, 제외 0개, 4요소 각각 응답 30개입니다. 분산은 /n, 중간값을 반올림하지 않고 최종 표시만 둘째 자리까지 반올림합니다. 재미 척도는 설명용 1~5 가정이며 실제 앱 척도 확인이 필요합니다. 교사용 재미 인원은 1점→5점 순서입니다. 안전성 평가가 높아도 필수 안전선 확인을 대신하지 않습니다.

| 종목 | 평균 | 분산(/n) | SD | 재미 평균 |
|---|---:|---:|---:|---:|
| 컵 / 개 | 10.00 | 8.00 | 2.83 | 3.80 |
| 솜공 / 개 | 10.00 | 2.00 | 1.41 | 3.00 |
| 표적 / 회 | 1.40 | 1.04 | 1.02 | 3.60 |
| 절대오차 / 초 | 0.60 | 0.08 | 0.28 | 2.60 |
| 바구니 / 회 | 1.60 | 1.04 | 1.02 | 3.60 |

분산 단위는 각각 개²·회²·초²입니다. 교사용 추천은 **명시적 가상 앱 추천**으로 ‘솜공 옮기기’를 설정했으며 산출 점수나 계산된 순위를 주장하지 않습니다. 모둠은 바구니를 제안하는 한 사례이고 다른 기준·선택도 가능합니다. 누락 지도용 3칸 사례는 별도이며 30행 통계에 합치지 않습니다. 가상 진단 A/B도 학급 자료와 별개입니다.

실제 수업 전 교사는 줄바꿈·쪽 수·필기 공간을 마지막으로 확인하고, 가상 예시를 실제 학급 결과로 제시하지 마세요.

## 제작 시 렌더링 확인

기존 Chrome과 Node v24.16.0의 WebSocket으로 Chrome DevTools Protocol을 사용했습니다. 별도 의존성을 설치하지 않았습니다. 임시 폴더의 `check-sheets.cjs`를 `node C:\Users\USER\AppData\Local\Temp\opencode\check-sheets.cjs`로 실행하여 6개 수업 파일을 로컬 file URL로 열고 `Page.printToPDF(preferCSSPageSize: true)`를 호출했습니다. PDF Page 객체 수는 학생용 3·4·2쪽, 교사용 3·4·2쪽이었습니다. 각 명시적 쪽의 마지막 내용과 바닥글 사이에는 양의 여유가 있었고 최소 약 65px였습니다. 제안서도 각 파일 4쪽째 한 페이지에 유지되었습니다.

390px 화면에서 7개 HTML의 가로 스크롤 넘침이 없음을 DOM 너비로 확인했습니다. 모바일 교사용 2차시 캡처와 인쇄 미디어의 완성 제안서 캡처를 눈으로 확인했습니다. PDF·PNG·브라우저 임시 프로필은 저장소가 아닌 승인된 임시 폴더에만 생성했습니다. PDF 쪽 수와 DOM 치수는 확인했으나 모든 PDF 페이지를 래스터화해 눈으로 검수한 것은 아닙니다. 실제 프린터·다른 운영체제 글꼴·교실 운영은 미검증입니다. 수학과 수업안 일치의 최종 검토는 별도로 필요합니다.
