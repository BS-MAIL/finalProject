# 새 주제 CBL·TRACES 설계 프롬프트 모음

> 목적: 교사가 기존 원문을 고르지 않고 새 주제를 정할 때, 수업의 핵심 판단·수학·안전 경계·6차시 흐름을 먼저 설계하도록 돕습니다.
>
> 사용법: 대괄호를 수업 상황으로 바꾼 뒤 AI 또는 동료 교사에게 요청합니다. AI의 제안은 초안일 뿐이므로 성취기준 원문, 수학 계산, 자료 출처, 학교 규정은 사람이 확인합니다. 실제 학생·교직원·시설의 식별 정보, 사진, 계정 정보는 입력하지 않습니다.

## 공통 입력 틀

아래 네 가지를 먼저 적으면 어떤 프롬프트도 훨씬 구체적으로 작동합니다.

- 학년·과목·단원 또는 확인할 성취기준: [ ]
- 수업 시간과 차시 수: [기본 6차시, 차시당 __분]
- 사용할 수 있는 자료: [교사 제공 가상 자료 / 공개 자료 / 비식별 자료]
- 피할 자료·활동: [개인정보, 실제 시설 변경, 외부 조사 등]

## 1. 새 주제 후보를 찾는 프롬프트

```text
나는 [학년·과목·단원]에서 6차시 CBL 수업 주제를 새로 정하려 한다.
학생은 [핵심 수학 개념]을 이용해 실제 또는 가상 맥락의 선택 문제를 다룬다.
사용 가능한 자료는 [자료 범위]이고, [금지·안전 경계]는 지켜야 한다.

다음 조건을 만족하는 주제 후보 5개를 제안해라.
- 학생이 질문·가정·비교 기준·해결안 중 적어도 하나를 선택할 수 있을 것
- 수학 계산·표·그래프가 해결안 선택에 실제로 쓰일 것
- 교사 제공 가상 자료만으로도 운영 가능할 것
- 첫 선택을 다른 조건에서 시험할 E 단계가 가능할 것

각 후보마다 ① Challenge 초안 ② 필요한 수학 ③ A에서 비교할 후보 ④ E에서 줄 다른 조건 ⑤ 안전한 자료 범위를 표로 정리해라.
확인할 수 없는 교육과정 코드나 실제 통계는 만들지 말고 [교사 확인 필요]로 표시해라.
```

## 2. 주제가 CBL에 맞는지 점검하는 프롬프트

```text
다음 수업 주제가 CBL에 적합한지 검토해라.
주제: [주제]
학년·수학 개념: [ ]
학생에게 줄 자료: [ ]
학생이 내릴 선택: [ ]
예상 산출물: [ ]
안전·개인정보 경계: [ ]

다음 다섯 항목을 각각 '충족 / 보완 필요 / 부적합'으로 판단하고 이유를 짧게 써라.
1. 계산 과제가 아니라 학생의 판단 문제인가?
2. 수학이 결론의 근거가 되는가?
3. 학생 선택권과 교사 고정 조건이 구분되는가?
4. A의 첫 선택을 E에서 다른 조건으로 시험할 수 있는가?
5. 가상·공개·비식별 자료로 안전하게 운영 가능한가?

보완이 필요하면 주제를 버리지 말고 가장 작은 수정안을 제안해라.
```

## 3. Challenge 문장을 만드는 프롬프트

```text
[학년] 학생이 [수학 개념]을 사용해 다룰 CBL Challenge를 3개 제안해라.
맥락: [ ]
학생이 선택할 수 있는 것: [질문 / 자료 / 가정 / 비교 기준 / 해결안]
교사가 고정할 것: [성취기준, 수학 표현, 자료 범위, 안전선, 검산 기준]

Challenge는 정답·방법·산출물을 미리 지시하지 말고,
학생이 여러 후보를 수학적 근거로 비교·정당화할 수 있게 써라.
각 문장 아래에 '학생이 실제로 결정하는 것'과 '교사가 고정하는 것'을 한 줄씩 붙여라.
```

## 4. A와 E를 분리하는 프롬프트

```text
다음 수업에서 A(해결안 설계)와 E(다른 조건에서의 시험)가 겹치지 않게 설계해라.
주제와 수학 모형: [ ]
A에서 학생이 사용할 첫 자료·조건: [ ]
A에서 비교할 후보: [ ]

다음 형식으로 작성해라.
- A: 학생이 계산·표·그래프를 이용해 어떤 후보를 어떤 기준으로 고르는가?
- C: E 전에 무엇을 예측하고, 어떤 판정 기준·중단 조건을 정하는가?
- E: A에서 쓰지 않은 자료·조건·시험점은 무엇인가? 그 조건은 왜 선택을 실제로 시험하는가?
- S: 결과가 달라질 때와 같을 때 학생이 각각 어떤 판단을 기록하는가?

단순 재계산, 같은 표본의 반복 대입, 발표만을 E로 제안하지 마라.
```

## 5. TRACES 6차시 뼈대를 만드는 프롬프트

```text
다음 조건으로 TRACES 6차시 수업의 초안을 만들어라.
주제: [ ]
학년·수학 개념: [ ]
학생이 최종적으로 내릴 판단: [ ]
자료 범위와 안전 경계: [ ]
A의 첫 자료·후보: [ ]
E의 다른 시험 조건: [ ]

T, R, A, C, E, S 각각에 대해
1. 학생이 답할 질문
2. 핵심 활동
3. 학생이 남길 짧은 증거
4. 교사가 확인할 오개념 또는 안전 경계
5. 다음 차시로 이어지는 연결
을 표로 써라.

새 수치·성취기준·사실을 지어내지 말고 필요한 정보는 [교사 확인 필요]로 표시해라.
```

## 6. 수학 모형을 점검하는 프롬프트

```text
다음 CBL 수학 모형을 검토해라.
변수와 단위: [ ]
식·표·그래프: [ ]
연속적으로 탐구할 범위: [ ]
실제 선택 후보의 범위: [ ]
학생이 내릴 선택: [ ]

다음을 표로 점검해라.
- 변수 뜻과 단위가 일관되는가?
- 정의역·범위와 제외값이 설명되는가?
- 계산을 직접 대입, 단위, 그래프, 반례 중 무엇으로 검산할 수 있는가?
- 연속 탐구와 이산적인 실제 선택을 혼동하지 않는가?
- 모형이 말할 수 없는 한계는 무엇인가?

오류가 있다면 정답을 단정하지 말고, 교사가 확인할 질문과 최소 수정 방향을 제시해라.
```

## 7. 활동지와 평가 증거를 만드는 프롬프트

```text
다음 TRACES 수업에서 학생용 활동지와 교사용 기록을 설계해라.
주제: [ ]
차시: [T/R/A/C/E/S 중 하나]
학생의 핵심 판단: [ ]
학생이 사용할 자료·수학: [ ]
학생용에 넣으면 안 되는 정답·개인정보: [ ]

학생용 활동지에는 빈 작업 공간, 판단 기준, 근거 작성 칸만 제안해라.
교사용에는 완성 예시, 예상 오개념, 확인할 개인 증거를 별도로 제안해라.
모둠 산출물만으로 평가하지 말고 학생 한 명이 자기 판단을 설명할 수 있는 개인 증거 하나를 포함해라.
```

## 8. 안전·AI 사용 경계를 점검하는 프롬프트

```text
다음 CBL 수업의 안전·개인정보·AI 사용 경계를 점검해라.
수업 활동: [ ]
자료: [ ]
AI를 쓰는 경우의 목적: [ ]
학교에서 피해야 할 정보·행동: [ ]

다음을 세 칸 표로 써라.
1. 해도 되는 것
2. 하지 않는 것
3. 문제가 생기면 바꿀 안전한 대체안

AI 사용은 선택 사항으로 두고, 사용한다면 학생이 직접 할 판단·검산 방법·입력 금지 정보를 구체적으로 적어라. 실제 효과나 실제 수요자 반응을 근거 없이 주장하지 않게 해라.
```

## 9. 동료 교사 검토를 받는 프롬프트

```text
다음 CBL·TRACES 수업안 초안을 동료 교사 관점에서 검토해라.
[수업안 붙여넣기]

다음 순서로만 답해라.
1. 학생이 실제로 하게 될 판단을 한 문장으로 요약
2. 유지할 강점 2개
3. 수학적 또는 수업 흐름상 가장 큰 결손 2개
4. A와 E가 겹치는지 여부와 가장 작은 수정
5. 교사가 확정 전에 답해야 할 질문 3개

근거 없는 성취기준·수치·학교 상황을 만들지 말고, 확인하지 못한 것은 '확인 필요'로 적어라.
```
