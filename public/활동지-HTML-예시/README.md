# Paper CSS 활동지 HTML 예시

이 폴더는 학생 활동지와 교사용 예시를 HTML로 만들 때 참고할 수 있는 A4 인쇄 예시입니다. 완성 HTML·PDF·PNG는 기존 원칙대로 이 저장소 밖의 제작 작업 폴더에서 관리합니다. 이 파일들은 공통 양식이나 그대로 제출할 기본 틀이 아닙니다. 교사는 차시의 핵심 판단, 수학, 자료, 학생의 기록 방식에 맞게 구조를 새로 구성하거나 크게 고쳐 써야 합니다.

## Paper CSS를 쓰는 이유

Paper CSS는 입력 칸, 버튼, 표, 카드에 손그림 같은 가벼운 질감을 주는 CSS 라이브러리입니다. 활동지에서 중요한 것은 장식이 아니라 학생이 읽고, 계산하고, 근거를 쓸 공간을 빠르게 만드는 일입니다. 따라서 Paper CSS는 기본 골격으로만 쓰고, 이 폴더의 인쇄 CSS가 A4 여백·글자 크기·페이지 나눔을 담당합니다.

- `assets/paper.min.css`는 Paper CSS `1.9.2`의 로컬 복사본입니다.
- 외부 CDN, 외부 폰트, 추적 스크립트를 쓰지 않으므로 오프라인에서도 같은 모양으로 열 수 있습니다.
- Paper CSS의 화면용 그림자·장식은 인쇄에서 줄이고, 표·입력 칸·수식·그래프 공간을 우선합니다.

## 사용할 때의 순서

1. 아래 예시 가운데 수업의 **학생 판단**과 가장 가까운 정보 구조를 참고한다.
2. 차시에서 학생이 실제로 내려야 할 판단과 필요한 수학 증거를 먼저 다시 설계한다.
3. 필요한 경우 HTML을 별도 제작 작업 폴더로 복사하되, 제목만 바꾸지 말고 표·질문·기록 공간·페이지 수를 수업안에 맞게 고친다.
4. 브라우저에서 먼저 읽고 쓴 뒤 PDF로 인쇄 미리보기를 확인한다.
5. 학생용에는 정답·완성 계산을 넣지 않고, 교사용 예시는 별도 파일로 복사해 작성한다.

| 파일 | 잘 맞는 차시 | 중심 구조 |
|---|---|---|
| `01-탐구-판단-활동지.html` | T, R, A | 문제 관찰 → 자료·조건 → 계산·근거 → 첫 판단 |
| `02-시험-수정-활동지.html` | C, E, S | 예측 → 다른 조건 시험 → 결과 → 수정·유지 이유 |
| `03-모델-비교-활동지.html` | A, C | 후보 A/B 비교 → 수학 검산 → 기준 → 시험 계획 |
| `04-교사용-예시-기록지.html` | 교사용 | 공통 모델·예상 오개념·개인 증거·관찰 기록 |

## 학생용과 교사용을 분리하는 법

학생용 파일은 질문·자료·빈 표·그래프 축·근거 공간까지만 둡니다. 교사용 예시는 학생용 파일을 복사한 뒤에만 완성 계산, 예상 오개념, 관찰 기준을 넣습니다. 학생용과 교사용을 한 PDF나 한 HWPX 쪽에 섞지 않습니다.

## 인쇄 확인

- A4 세로, 기본 여백 12mm를 기준으로 합니다.
- Chrome 인쇄 창에서 배경 그래픽을 켜고, 배율은 기본값부터 확인합니다.
- 표 잘림, 수식 겹침, 작은 글자, 흑백 대비, 학생이 실제로 쓸 빈 공간을 확인합니다.
- 한 페이지에 억지로 넣기 위해 글자를 10pt 미만으로 줄이지 않습니다. 내용이 길면 활동지를 두 쪽으로 나눕니다.

## AI에 예시를 바탕으로 새 활동지를 요청할 때

```text
첨부한 HTML은 A4 학생 활동지의 참고 예시일 뿐이며, 그대로 제출할 기본 양식이 아니다.
Paper CSS 로컬 파일 `assets/paper.min.css`를 활용할 수 있으나, 수업의 판단과 기록 방식에 맞게 레이아웃을 새로 설계해라.
외부 CDN, 외부 폰트, 추적 스크립트, 이미지 생성은 추가하지 마라.

차시: [ ]
학생의 핵심 판단: [ ]
학생이 사용할 수학·자료: [ ]
학생용에 넣으면 안 되는 정답·개인정보: [ ]

제목, 안내 문장, 표의 열 이름, 빈 기록 칸만 수업에 맞게 고쳐라.
A4 한 페이지에서 글자 12pt 이상, 학생이 직접 쓸 공간, 흑백 인쇄 가독성을 유지해라.
학생용에는 완성 답·교사용 해설을 넣지 마라.
```

Paper CSS 원본의 라이선스와 세부 정보는 `assets/paper.min.css`의 헤더를 확인합니다.
