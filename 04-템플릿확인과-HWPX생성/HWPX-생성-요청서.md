## 템플릿 사전 확인

- [ ] 템플릿 원본과 작업용 복사본을 분리했다.
- [ ] 템플릿을 실제로 열어 단원·표·수식 영역·머리말·쪽 구성을 확인했다.
- [ ] `unzip -t`로 템플릿 ZIP 무결성을 확인했다.
- [ ] `kordoc` 역추출로 제목·표·차시별 입력 영역을 확인했다.
- [ ] 템플릿 복사본과 시험용 `content.py`로 1개 차시를 생성·열람했다.

## 생성 금지 사항

- [ ] 원문 근거가 없는 내용을 추가하지 않는다.
- [ ] `교사 확인 필요`, `재구성 제안`, 빈 대괄호를 포함하지 않는다.
- [ ] 승인 템플릿의 표 구조·셀 주소·수식 영역을 임의 변경하지 않는다.
- [ ] HWPX ZIP/XML을 문자열 치환으로 직접 편집하지 않는다.
- [ ] HWPX 결과물과 템플릿 바이너리를 이 저장소에 넣지 않는다.

## 인수 확인

- [ ] 확정 수업안의 총 차시와 생성 대상 차시가 일치한다.
- [ ] 확정 수업안이 한 주제의 TRACES 6차시 수업지도안이며, 차시별 중간 산출물과 최종 성과물이 연결돼 있다.
- [ ] `content.py`의 `COMMON`과 `CHASI[1]`~`CHASI[6]`이 확정 Markdown과 일치한다.
- [ ] Challenge·학생 주도 선택·Act 피드백 및 수정이 구체적으로 확정돼 있다.
- [ ] 성취기준·안전 경계·A0~A4·예상 산출물이 모두 입력돼 있다.
- [ ] 검증 담당자에게 전달할 최종 파일명·버전·SHA-256·생성 엔진·템플릿 버전을 기록할 준비가 됐다.
