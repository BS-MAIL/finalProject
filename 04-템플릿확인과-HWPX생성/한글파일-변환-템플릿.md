# 한글파일 변환 템플릿

> 용도: 검토·확정된 Markdown 수업안을 HWP/HWPX로 변환하기 전, 원문 근거와 재구성 내용을 분리하여 구조·확인 항목을 맞추는 템플릿이다.
>
> 이 문서는 수업 내용 초안이 아니다. `[대괄호]`는 확정 Markdown의 내용으로만 채운다. `재구성 제안` 또는 `교사 확인 필요` 항목은 확인 전 HWP/HWPX 확정본에 넣지 않는다.

## 9. 변환 전 확인표

- [ ] 기준 원문 파일, 원문보존본 경로, 원문 쪽·문장을 기록했다.
- [ ] 원문 사실, 재구성 제안, 교사 확인 필요 항목을 구분했다.
- [ ] 실제 대상자 반응을 요구하지 않았으며, 원문이 가상·안전 경계를 정한 경우 미수집 사유와 대체 피드백을 기록했다.
- [ ] 차시별 계획표와 산출물표의 행 수가 `총 차시`와 같다.
- [ ] 각 차시에 A0, A1, A2, A3, A4의 적용 내용 또는 해당 없음 사유가 있다.
- [ ] 개인정보·보안정보 입력 금지와 AI 검증 방법을 적었다.
- [ ] 원문 수식, 표, 성취기준, 인용·출처를 대조했다.
- [ ] 교사 검토 상태가 `확정`이다.

## 10. HWP/HWPX 변환 후 확인표

- [ ] 제목, 표, 수식, 글머리표가 확정 Markdown과 일치한다.
- [ ] 표가 페이지 밖으로 넘치거나 잘리지 않는다.
- [ ] 총 차시 수와 차시별 계획표·산출물표의 행 수가 일치한다.
- [ ] A0~A4, 원문/제안 구분, 근거, 확정 상태 열이 모두 보인다.
- [ ] 원문 인용 및 출처가 유지된다.
- [ ] 변환한 HWP/HWPX를 다시 Markdown으로 추출하여 내용·쪽수·표를 대조했다.
- [ ] 최종 파일명, 버전, 생성일, 검증 결과를 기록했다.
