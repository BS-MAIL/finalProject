## 5. 차시별 수업 계획

> 기본 구조는 TRACES 6차시다: ① T 문제 포착·도전 정식화 → ② R 질문 기반 탐구 → ③ A 수학적 해결안 설계 → ④ C 실행 계획 → ⑤ E 제한 실행 → ⑥ S 실행 증거 해석·수정·성찰.
>
> 실제 적용·외부 협력·장기 관찰이 필요한 주제는 6차시 이후에 실행·관찰·수정 차시를 확장한다. `총 차시`와 같은 수의 행을 만들고, `[추가]` 같은 포괄 행으로 여러 차시를 합치지 않는다.
>
> 각 칸은 확정된 내용만 적는다. A0~A4는 AI를 사용하는 핵심 차시에만 기록하며, AI 미사용 차시는 `AI 미사용`으로 표시한다. `예상 산출물`은 해당 차시에 학생이 실제로 남기는 중간 또는 최종 성과물이어야 한다.

## 7. HWPX 생성 전 최종 확인

- [ ] 문서 상태가 `확정`이다.
- [ ] 모든 원문 사실과 재구성 제안에 근거가 있다.
- [ ] `교사 확인 필요` 또는 빈 대괄호 항목이 없다.
- [ ] 총 차시가 기본 6차시 TRACES 이상이고, 차시별 계획 행과 산출물 행 수가 일치한다.
- [ ] 학생 주도 선택(질문·자료·조건·해결안·역할)이 구체적으로 기록돼 있다.
- [ ] Challenge가 학생에게 답·방법·산출물을 미리 지정하지 않고, 해결 방향을 선택·정당화할 여지를 둔다.
- [ ] Act가 발표만으로 끝나지 않고 시험·공유·피드백·수정 또는 미수정 사유·한계 기록으로 이어진다.
- [ ] 각 차시에 중간 또는 최종 성과물이 있으며, 차시 흐름과 연결된다.
- [ ] 각 차시에 A0~A4 또는 해당 없음 사유가 있다.
- [ ] 안전·개인정보·보안 경계가 원문 근거와 일치한다.
- [ ] 수식, 표, 성취기준, 출처를 확인했다.
