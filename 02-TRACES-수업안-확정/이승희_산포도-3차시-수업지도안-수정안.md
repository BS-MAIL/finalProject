### 3차시와 TRACES의 관계

템플릿을 6차시로 늘려 적용하지 않는다. 1차시는 문제 포착과 체험 자료 수집(T/R), 2차시는 기준 설정·분석·추천안 설계(R/A 및 계획 요소), 3차시는 근거 공유·질문·성찰(S 중심)으로 대응시킨다. **발표를 E(제한 실행)의 완료 증거로 쓰지 않는다.** 1차시 체험은 추천안 설계 이전의 자료 수집이며, 설계 후 별도 시험이나 실제 학급 행사 운영은 이 3차시 범위에 없다. TRACES 전 단계의 실행을 완료한 수업이라고 표시하지 않는다.

## 2. 학생이 해결할 문제

### Big Idea

기록의 고름과 즐거움은 같지 않다. 통계와 서로 다른 경험을 함께 읽어 공동체의 선택을 정당화한다.

### Essential Question

**기록이 고르면 모두 즐거울까?**

### Challenge: 학생에게 그대로 제시할 과제

> 학급 모두가 즐길 체험 행사 종목 하나를 추천하라. 학급 전체의 수행 기록과 재미 평가·익명 의견을 살펴보고, 모둠이 정한 기준에 따라 선택하라. 앱 추천에 대한 의견과 선택한 종목의 한계도 밝혀라.

실제 체험에서 수집할 자료로 추천안을 만드는 과제다. 행사 개최·채택 또는 모든 학생의 즐거움이 입증되는 것은 아니다. 모둠은 하나씩 추천하며, 발표 경쟁이나 개인·모둠 기록 순위 결정은 하지 않는다.

| 학생이 정하는 것 | 교사가 고정하는 것 |
|---|---|
| 중요한 기준 3개, 우선순위와 이유 | 동일한 5종목·기록 정의·기구·거리·규칙, 학급 전체 자료 범위 |
| 종목 선택, 통계·평가 근거, 앱 추천에 대한 입장 | /n 계산, 비교 한계, 비식별 공유, 발표·질의 시간 |
| 역할 분담, 제안의 한계와 보완 조건 | 필수 안전수칙과 중단 조건. 위험을 재미 등 다른 점수로 상쇄할 수 없음 |

기준은 배점표가 아니다. 모둠이 앱 배점이나 별도의 가중 점수를 만들지 않고, 중요도 순서와 그 이유를 언어로 정한다. 참여가능성은 별도 설문을 추가하지 않고 체험 경험과 기존 평가·익명 의견을 토대로 모둠 토론에서 확인한다.

## 3. 자료·수학 모델·안전 경계

### 3.1 자료와 공개 순서

1. 1차시에 종목별 실제 수행 기록, 기존 앱의 재미·공정성·안전성·준비 용이성 평가, 종목별 짧은 익명 의견을 수집한다. 재미는 평균만이 아니라 응답 분포를 남긴다.
2. 종목에서 측정을 마친 학생은 안전한 기록 자리에서 자기 기기로 기록·4요소 평가와 짧은 의견을 입력한다. 정리 구역에서는 이미 체험한 종목의 누락·오입력만 보완한다. 아직 체험하지 않은 종목을 평가하지 않는다.
3. 1차시 말 교사는 학급 전체 집계 대상, 종목별 유효 자료 수와 평가 응답 수를 확인한다. 학급 집계 기능이 준비되어 있다는 전제이며, 현재 집계가 검증되었다는 서술이 아니다.
4. 2차시 기준 설정 전에는 추천·순위와 분석 화면을 보지 않도록 안내한다. 교사는 수집 화면만 안내하고 학생도 분석 화면을 열지 않는다. 별도의 접근 차단 기능이 검증되었다고 가정하지 않는다.
5. 기준 기록 후 분석 시작 시점부터 **학급 전체 통계·그래프·재미 평가 분포·익명 의견·학급 전체 기준 앱 추천을 함께 공개**한다. 조별 추천을 학급 추천으로 대신하지 않는다.

| 자료 | 성격·활용 | 경계 |
|---|---|---|
| 수행 기록 | 수업에서 수집할 실제 자료, 종목별 n·평균·분산·표준편차·분포 | 학생별 우열 공개 금지, 미참여를 임의로 0 처리 금지 |
| 4요소 평가 | 개인별 독립 응답을 학급 전체로 집계 | 재미 평균만으로 소수의 낮은 평가를 숨기지 않음. 응답 수·분포 확인 |
| 짧은 익명 의견 | 종목마다 한 문장 정도, 즐겁거나 불편했던 점과 이유 | 실명·다른 학생 지목·건강정보를 쓰지 않음. 교사가 공유 전 확인 |
| 진단 자료 | 아래에 제시한 가상 기록 | 실제 학급 기록과 혼동하거나 실제 체험 결과로 제시하지 않음 |
| 사진 | 선택 사항, 교사가 도구 배치만 촬영 | 학생 얼굴·실명·명찰·화면 식별자 촬영·공유 금지 |

### 3.2 수학적 해석과 검산 기준

종목별로 입력된 유효 자료 전체를 대상으로 한다. 실제 수집 전이므로 수치 결과를 미리 만들어 쓰지 않는다.

| 항목 | 식·단위·확인 | 해석 경계 |
|---|---|---|
| 자료 수 | n = 해당 종목의 유효 기록 개수, 최대 30 | 종목별로 n이 다를 수 있음. n=0이면 통계 산출 불가, n=1이면 분산 0이어도 고른 학급이라고 해석 불가 |
| 평균 | x̄ = Σxᵢ/n, 원자료 단위 | 평균만으로 개인차나 재미를 알 수 없음 |
| 분산 | Σ(xᵢ-x̄)²/n, 원자료 단위의 제곱 | n-1을 쓰지 않음. 긴 전원 손계산 대신 입력·n·식·단위 점검 |
| 표준편차 | √분산, 원자료와 같은 단위 | 해당 종목 안에서 평균 주변 퍼짐을 그래프와 함께 설명 |
| 분포 | 몰림·흩어짐·극단값·0의 빈도 등 | 수치만 나열하지 않고 기록 범위·과제 특성과 연결 |
| 종목 간 비교 | 단위뿐 아니라 난이도·척도·가능한 기록 범위를 확인 | 개 단위인 컵과 솜공도 SD 직접 우열 비교 금지. 회 단위인 두 던지기도 같은 0~3 범위라는 이유만으로 난이도가 같지는 않음 |

- 표준편차가 작다는 것은 기록이 고르다는 정보이지, 공정함·재미·참여가능성을 보장하지 않는다. 모두 어려워 0에 몰리거나 너무 쉬워 최고값에 몰릴 수도 있다.
- 투척 두 종목은 3회 중 성공 횟수 0~3의 거친 자료다. 적은 시도에 따른 우연과 측정 시점의 영향을 한계로 쓴다. 다른 종목의 기록이 클수록 좋은 것과 달리, 10초 감각의 절대오차는 작을수록 목표에 가깝다.
- 미참여·측정 실패는 재측정 없이 빈칸으로 두고 계산에서 제외한다. 정상적으로 3회 시도했으나 모두 실패한 **실제 성공 0회**는 유효 기록이다. 컵·솜공도 정상 수행 결과 0개와 미측정을 구분한다.
- 발표에는 n과 제외가 결론에 미치는 한계를 표시한다. 개인별 미참여 사유나 건강정보 공개를 요구하지 않는다. 모든 학생의 체험을 계획하되 불편·통증이 있으면 강요하지 않고 기록·측정·안전 역할로 참여한다.
- 교사는 진단 예시나 짧은 표본으로 /n·단위 해석을 확인한다. 개념 전체 재강의나 모든 기록의 손계산으로 분석 시간을 대체하지 않는다.

### 3.3 앱 추천은 비판 검토 자료

원문의 설명은 **조원 평가 80점 + 일관성 20점**이며, 공정성·재미·안전성·준비 용이성 평가와 같은 단위 종목의 상대적 표준편차를 반영하는 방식이다. 원문에는 비교 대상이 부족하거나 표준편차가 모두 같으면 일관성 중립값 10점을 준다는 설명도 있다. 이 설명은 검토할 규칙이지, 이번 문서 작성에서 실제 코드를 확인한 결과가 아니다.

이번 설계에서는 학급 전체 자료·평가를 기준으로 한 앱 추천을 제시한다는 전제를 둔다. 원문의 조별 집계와 이번 학급 집계는 범위가 다름을 명시한다. 모둠은 80:20을 다시 설계하거나 점수를 만들지 않는다. 대신 다음을 묻는다.

- 같은 단위라는 이유만으로 일관성을 비교하면 난이도·척도 차이를 놓치지 않는가?
- 평가 평균은 재미를 낮게 평가한 학생의 경험이나 익명 의견을 가리지 않는가?
- 작은 SD에 가점을 주는 것이 학급 모두의 즐거움을 뜻하는가?
- 앱과 같은 결론이어도 모둠의 우선 기준과 이유가 다를 수 있는가?

동의·반대·같은 결론이지만 다른 이유 모두 허용한다. 앱의 추천 1위를 정답으로 평가하지 않는다. 별도의 생성형 AI 사용은 요구하지 않으며, 개인정보를 외부 AI에 입력하지 않는다.

## 4. 1차시: 5분 진단 후 다섯 종목 체험·자료 수집

### 4.1 사전배치와 공통 운영

- 교사는 수업 전에 기구·거리 표시·순환표·기록 용지·접속 안내를 배치한다. 수업 중 설치 시간을 따로 요구하지 않는다.
- 바람 없는 장소에서 5종목 구역과 기록 정리 구역을 둔다. 투척 두 구역은 동일한 안전 방향을 사용하되 회수 동선과 대기선을 분리하고 다른 구역을 향해 던지지 않는다.
- 동일 종목의 도구 크기·재질·수량, 표적·바구니 위치, 투척 거리, 시간·성공 판정 규칙은 모든 모둠에 동일하다. 정확한 거리·도구 규격은 교사가 예비운영 후 수업 전에 고정할 미확정 운영값이다. 모둠이 임의로 바꾸지 않는다.
- 종목별 도구는 1~2세트 범위다. 오래 걸리는 컵·솜공은 **2세트 권고**: 한 세트를 쓰는 동안 다른 세트를 초기화한다. 아래 시간 추정은 5명 순차 측정 기준이며, 동시 측정으로 시간을 절반으로 줄였다고 가정하지 않는다.
- 여기서 세트는 **도구 묶음 수**다. 측정은 학생당 종목별 1회이며, 투척 종목의 1회 측정은 3회 던지기 전체다. 긴 사전 연습과 추가 재측정은 하지 않는다. 시범을 본 뒤 측정한다.
- 5명은 수행·측정·기록 대조·초기화·안전 역할을 교대한다. 수행자 외 학생은 자기 차례가 끝나면 입력·평가를 병행하되 투척·회수 중 기기를 보지 않는다.

최장 예산은 175초+입력·평가·의견 75초=250초로, 회전당 285초 중 35초를 남기는 안이다. 30명 접속, 마지막 수행자의 응답 속도, 실제 회수 시간이 이 안에 들어오는지 반드시 사전 예비운영으로 확인해야 한다. 넘치면 수업 전에 도구·동선·입력 안내를 개선하고 시간표를 재검토한다. 학생을 재촉하거나 안전 회수를 생략해 맞추지 않으며, 2차시로 측정이 넘어가면 본 초안의 목표 미달로 기록한다.

수행 기록의 높고 낮음, 앱 추천 일치 여부, 선택 변경 여부, 실제 행사 채택·성공 여부는 평가하지 않는다. 안전상 수행하지 못한 학생도 분석·의사소통 증거로 평가한다.

## 9. 안전·개인정보·장애 대안

### 안전과 참여

교사의 기본 안전수칙은 필수 조건이다. 뛰기·신체 접촉·지정 종목과 방향 외의 임의 투척·투척 중 투척선 앞 진입을 금지한다. 투척 중에는 회수하지 않고, 중지·회수 신호 뒤 전원이 멈춘 것을 확인한 후 회수한다. 큰 솜공과 종이공은 입에 넣지 않고 바닥의 도구를 바로 정리한다. 바람·미끄럼·충돌 위험이 생기면 중단한다. 통증·불편은 교사에게 개별적으로 알리고 대체 역할을 맡으며 건강정보를 학급에 설명하도록 요구하지 않는다.

안전·참여 조건은 모둠의 평가·토론 항목이지만, 교사가 정한 기본 안전선은 선택 사항이 아니다. 낮은 안전성을 높은 재미 점수로 보상하지 않는다. 모든 학생·모둠의 5종목 체험을 계획하되, 개인의 안전 중단·미참여·측정 실패는 재측정 없이 빈칸과 n의 한계로 처리한다.

### 개인정보와 보관

입력에는 교사가 정한 번호·별칭을 사용하고 실명을 쓰지 않는다. 공유·투사·발표 자료에서는 번호·별칭 등 식별자를 제거하고 학급 통계·비식별 분포만 보여 준다. QR·접속 주소와 개별 화면을 외부에 공개하지 않는다. 사진은 선택 사항이며 교사가 도구 배치만 촬영하고 학생 얼굴·실명은 포함하지 않는다. 익명 의견에는 건강정보를 적지 않는다. 자료·기기 세션·선택 사진의 보관 기간과 사용 후 삭제는 교사가 학교 기준에 따라 정하고 안내한다. 이 문서는 실제 삭제나 보안 점검이 완료되었다고 주장하지 않는다.

### 앱 장애 시 짧은 종이 대안

접속·저장 장애 시 복구 시도로 회전 시간을 소비하지 않고 번호·별칭 종이표에 기록·기존 4요소 평가·짧은 의견을 수집한다. 교사는 차시 사이 학급 실제 자료를 집계하고 계산기로 통계와 간단한 분포표를 준비하는 대안을 둔다. 긴 손계산을 학생 전원에게 전가하지 않는다. 2차시에도 기준을 먼저 적고 학급 자료를 함께 공개한다.

앱 추천을 확보하지 못했으면 “앱 추천 미확인”으로 표시하고 원문 80+20 규칙의 한계만 검토한다. 실제 추천 결과를 지어내거나 과거·가상 자료를 이번 학급 자료처럼 쓰지 않는다. 이 경우 앱 추천에 대한 실제 동의·반대 활동은 미완료로 기록한다. 한 장 제안서와 3차시 발표·질문 24분, 개인 전후 기록은 종이로 유지한다.
