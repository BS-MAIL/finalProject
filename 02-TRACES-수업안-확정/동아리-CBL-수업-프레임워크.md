# 동아리 CBL 활동 프레임워크: TRACES

> 동아리의 기본 운영 단위는 한 주제, **6차시**, 여섯 단계다. 학생은 문제와 도전을 정식화하고(Trigger), 질문 기반으로 탐구하며(Research), 수학적 해결안을 설계하고(Architect), 실행을 계획한 뒤(Change-plan), 안전한 맥락에서 제한 실행하고(Execute), 실행 증거를 해석해 수정·성찰한다(Study).
>
> **TRACES = Trigger → Research → Architect → Change-plan → Execute → Study**
>
> TRACES는 원래 CBL의 `Engage → Investigate → Act`를 동아리 활동의 실행 단위로 세분화한 프레임워크다. 주제와 교과는 달라도 단계, 학습 증거, 평가 원칙은 바꾸지 않는다.
>
> 5차시 TRACE형은 `Change-plan`과 `Execute`를 같은 차시에 압축하는 예외 운영안이다. 실제 또는 제한 실행이 필요한 활동의 기본형은 TRACES 6차시다.

## 1. 흔들리지 않는 여섯 단계

| 단계 | CBL 대응 | 학생의 핵심 질문 | 교사의 역할 | 다음 단계로 넘길 증거 |
|---|---|---|---|---|
| **T — Trigger / 문제 포착·도전 정식화** | Engage: Big Idea, Essential Question, Challenge | 무엇을 바꾸고 싶으며, 왜 이것이 문제인가? | 교육과정·시간·안전의 범위를 제시 | Big Idea, Essential Question, 문제 정의문, Challenge |
| **R — Research / 질문 기반 탐구** | Investigate: Guiding Questions, Activities, Resources | 무엇을 알아야 하며, 무엇을 기준으로 판단할까? | 자료 범위와 신뢰도·개인정보 경계 안내 | Guiding Questions, 탐구 활동, 자료·변수·조건표, 조사 기준 |
| **A — Architect / 수학적 해결안 설계** | Act: Solution Concepts | 어떤 수학적 모델과 해결안이 타당한가? | 필수 개념·표현·검산 기준을 지도하고 오류 교정 | 식·표·그래프, 가정, 해결안 후보 비교, 선택 근거 |
| **C — Change-plan / 실행 계획** | Act: implementation preparation | 해결안을 어디에서 어떻게 시험할까? | 저위험 범위, 중단 조건, 대체안 확인 | 대상·맥락, 실행물, 판단 기준, 안전·중단 조건, 기록 방식 |
| **E — Execute / 제한 실행** | Act: Solution Implementation | 계획한 해결안을 안전하게 어떻게 사용·시험할까? | 실행 범위와 관찰 기준을 확인 | 실행물 또는 모의 실행물, 실행 충실도, 관찰값·피드백, 중단·변경 기록 |
| **S — Study / 실행 증거 해석·수정·성찰** | Act: Evaluation | 판단 기준에 비추어 무엇을 수정·유지하며, 다른 상황에는 어떻게 적용할까? | 증거 해석과 개인 성찰 지원 | 수정 전후 비교, 한계, 유지·수정 이유, 최종 제안, 개인 성찰 |

## 2. 기본 운영 단위: 6차시 TRACES

| 차시 | 기본 단계 | 반드시 남길 학습 증거 |
|---:|---|---|
| 1차시 | T — Trigger / 문제 포착·도전 정식화 | Big Idea, Essential Question, 문제 정의문, Challenge |
| 2차시 | R — Research / 질문 기반 탐구 | Guiding Questions, 탐구 활동, 자료·변수·조건표, 자료 한계 |
| 3차시 | A — Architect / 수학적 해결안 설계 | 식·표·그래프, 가정, 해결안 후보와 선택 근거 |
| 4차시 | C — Change-plan / 실행 계획 | 대상·맥락, 실행물, 판단 기준, 안전·중단 조건, 대체안 |
| 5차시 | E — Execute / 제한 실행 | 실행물 또는 모의 실행물, 실행 충실도, 관찰값·피드백, 중단·변경 기록 |
| 6차시 | S — Study / 실행 증거 해석·수정·성찰 | 판단 기준 대비 결과, 수정 전후 비교, 한계, 최종 제안, 개인 성찰 |

### 6차시형 적용 조건

6차시 TRACES는 다음 조건에서 동아리의 압축형 최소 단위로 쓴다.

- 사전 승인되거나 교실 안에서 가능한 저위험 대상·맥락이 있다.
- 비식별·공개·교사 제공 자료를 우선 사용한다.
- 한 차시 안에 관찰 가능한 판단 기준이 있다.
- 실행이 수업 운영에 영향을 주면 중단하거나 원상 복구할 수 있다.
- 실행이 불가하면 명시적 모의 적용으로 전환한다.

학교 전체 적용, 외부기관 협력, 개인정보 수집, 장기간 전후 비교가 필요한 주제는 추가 차시 또는 동아리 시간 외 관찰 기간을 계획한다.

### 예외 운영: 5차시 TRACE

시간이 부족하고 4차시에 계획과 제한 실행을 함께 할 수 있을 때만 `Change-plan`과 `Execute`를 압축한다. 실행 계획만 남기고 실제·제한 실행을 생략하는 5차시형은 Act를 충족하지 못한다.

- 매 차시에 새 문서를 만들 필요는 없다. 누적 작업지, 관찰 기록, 짧은 구두 설명도 다음 판단에 쓰이면 학습 증거다.

## 3. Challenge 작성 공식

다음 세 요소를 한 문장에 넣는다.

`[우리의 문제/변화 대상]을 위해 [학생이 선택할 수 있는 기준·조건]을 바탕으로 [수학적 근거]를 사용해 어떤 해결안이 더 타당한지 제안하자.`

- 교사가 고정하는 것: 성취기준, 필수 수학 개념·표현·검산 기준, 시간, 안전·개인정보 경계
- 학생이 선택하는 것: 질문, 자료·변수·가정, 비교 기준, 해결안, 역할, 수정 여부
- 피할 것: 정답·방법·최종 산출물을 미리 정해 놓은 “계산 후 발표” 과제

## 4. Act의 최소 기준

Act는 발표나 검토 요청이 아니다. 학생이 수학적 근거로 선택한 해결안을 자신 또는 주변의 실제·안전한 맥락에서 **사용하거나 제한적으로 시험하는 행동**이다.

Act 계획에는 아래 다섯 항목을 모두 쓴다.

1. **대상/맥락**: 어디에서 누구를 위해 시험하는가?
2. **시험할 해결안**: 무엇을 실제로 사용하거나 적용하는가?
3. **판단 기준**: 무엇을 관찰하거나 비교하면 되는가?
4. **한계와 중단 조건**: 무엇이 위험·부적절하면 멈추거나 원상 복구하는가?
5. **수정 여부**: 피드백 뒤 무엇을 바꾸거나 유지하며, 왜 그런가?

### Act 실행 수준

| 수준 | 사용 조건 | 예시 | 평가에서 보지 않는 것 |
|---|---|---|---|
| 교실 내 제한 시험 | 사전 합의한 저위험 활동에서 실제 적용 조건을 충족 | 안내물·선택 기준표를 수업 맥락에서 제한적으로 사용 | 실제 변화의 크기 |
| 학교 내 시험 | 담당자와 사전 협의하고 개인정보·운영 경계를 충족 | 사전 협의된 사용 맥락에서 모형·안내물을 시험 | 협력 승인 여부·응답 수 |
| 명시적 모의 적용 | 실제 적용이 안전·개인정보·수업 운영·승인·시간 조건 때문에 불가하거나 부적절하거나, 원문이 실제 관찰·개입을 금지 | 역할 기반 대상자·가상 시나리오·공개 자료로 시험 | 실제 대상자 반응 여부 |

모의 적용은 실제 적용처럼 쓰지 않는다. 대신 실제 적용과 다른 한계와, 실제 적용 시 추가로 확인할 조건을 기록한다.

## 5. 공정하고 간편한 평가 원칙

- **공통 모둠 증거**: 문제 정의, 자료·모델, 해결안, Act 기록, 수정 전후 비교
- **개인 증거 하나 이상**: 핵심 계산 또는 판단 설명, 역할 수행 기록, 개인 성찰
- **평가 기준 3~4개**: 수학적 정확성, 근거의 타당성, 안전·제약 분석, 시험 설계·증거 해석·수정 이유
- 외부협력의 승인, 실제 변화의 규모, 실제 수요자 반응의 수는 평가하지 않는다.
- 한계를 분석한 모의 적용은 동등한 평가 증거가 될 수 있다.

## 6. AI와 안전의 간편 원칙

- AI는 선택 사항이다. AI를 사용하지 않는 차시는 `AI 미사용`으로 표시하면 된다.
- AI를 사용하는 핵심 차시에서만 다음을 기록한다: 목적, 학생이 직접 하는 판단, 입력 경계, 검증 방법, 비식별화한 핵심 입력·출력 요약과 반영 이유.
- 실제 학생·교직원·시설 관련 정보는 가상 자료, 익명화된 공개 자료, 교사 제공 예시 자료로 대체할 수 있는지 먼저 확인한다.
- 외부 협력이 거절되거나 회신이 없으면 즉시 교사 제공 공개 자료, 교실 내 제한 시험, 또는 명시적 모의 적용으로 전환한다.
