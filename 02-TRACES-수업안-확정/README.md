# 2단계: TRACES 6차시 수업안 확정

## 목적

선정한 주제를 `Trigger → Research → Architect → Change-plan → Execute → Study`의 6차시 CBL 수업안으로 완성한다. 이 문서는 HWPX 생성의 유일한 내용 기준이다.

## 사용할 양식

[`../templates/확정-수업안-템플릿.md`](../templates/확정-수업안-템플릿.md)을 복사해 교사별 Markdown을 작성한다.

권장 파일명:

```text
교사명_과목_수업주제_TRACES6차시.md
```

## 작성 순서

1. 1단계 피드백 기록과 기준 원문을 읽고 기본 정보를 채운다.
2. 성취기준, Big Idea, Essential Question, Challenge를 작성한다.
3. 학생이 정할 질문·자료·조건·해결안·역할을 구체적으로 쓴다.
4. 1~6차시를 TRACES 단계에 하나씩 대응시키고, 각 차시의 목표·학생 활동·교사 지원·산출물·평가 증거를 쓴다.
5. Act에는 대상·맥락·실행물·판단 기준·안전·중단 조건·대체안을 모두 쓴다.
6. 실제 적용이 어렵다면 모의 적용임을 분명히 하고 실제 적용과 다른 한계를 기록한다.
7. AI 사용 차시는 목적·입력 경계·학생 직접 수행·검증·기록을 적고, 사용하지 않는 차시는 `AI 미사용`으로 쓴다.
8. 빈 대괄호, `교사 확인 필요`, 미확정 제안을 없앤 뒤 문서 상태를 `확정`으로 바꾼다.

## 완료 기준

- [ ] 한 주제와 기본 6차시 TRACES가 정확히 연결된다.
- [ ] 각 차시의 산출물과 평가·관찰 증거가 다음 차시의 판단으로 이어진다.
- [ ] 수학적 모델의 변수·단위·가정·검산이 해결안 선택과 연결된다.
- [ ] Act가 발표만으로 끝나지 않으며 안전·대체안이 있다.
- [ ] 모둠 증거 외에 개인 설명·역할 기록·성찰 중 하나 이상의 개인 증거가 있다.
- [ ] 문서 상태가 `확정`이고 미확정 표시가 없다.
