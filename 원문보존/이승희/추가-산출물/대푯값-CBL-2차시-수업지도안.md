2. 수업 설계 의도
2.1 학습자 분석
• 학생 수준: 자료를 읽고 사칙계산할 수 있으나 ‘대표한다’는 의미를 평균 계산과 동일
시하기 쉬운 중학생.
• 선행 지식: 자료의 수, 합계, 크기 비교, 표 읽기, 기본 계산기 사용.
• 예상 어려움: 중앙값을 최댓값과 최솟값의 평균으로 오해함, 최빈값이 반드시 하나라
고 생각함, 문자형 자료에 평균을 적용함, 자동 추천을 정답으로 수용함.
• 흥미 요소: 자신의 생활 자료가 즉시 반 전체 결과에 반영되고 조별 예측 게임으로 
이어지는 경험.
2.2 교육적 문제 상황
학생은 평균·중앙값·최빈값을 각각 계산해도 자료의 분포, 이상치, 유형과 조사 목적에 맞춰 
선택하는 데 어려움을 겪는다. 생활 자료를 직접 수집하면 대푯값이 실제 판단에 미치는 영
향을 경험할 수 있지만 입력 오류, 표본 대표성, 개인정보 문제가 생긴다. 따라서 앱의 빠른 
계산과 추천을 활용하되 활동지 정렬표·빈도표와 손계산으로 결과를 검증하고, 추천보다 근
거를 우선하는 수업으로 설계한다.
2.3 디지털 활용의 교육적 근거와 한계
• 앱은 여러 학생의 값을 실시간 수집하고 평균·중앙값·최빈값을 자동 계산하여 비교
·토론 시간을 확보한다.
• 숫자형 자료와 글자 답변 허용 문자형 자료를 구분하며, 문자형 자료는 최빈값과 빈
도로 다룬다.
• 자동 추천은 분포의 단순 규칙에 따른 판단 보조이며 정답이 아니다. 학생은 원자료, 
이상치, 반복값, 자료 목적과 표본 대표성을 근거로 동의하거나 반박한다.
• 앱에는 그래프나 점그림 기능이 없다. 분포 확인은 인쇄 활동지의 정렬표와 빈도표로 
보완하며 앱에 없는 기능을 사용했다고 기록하지 않는다.
• 학생 이름·번호가 저장될 수 있으므로 실명 대신 번호와 별칭을 사용하고, 민감한 주
제를 피하며 수업 후 불필요한 자료를 정리한다.

4.1 차시 목표
• 지식·이해: 평균·중앙값·최빈값의 뜻과 특징을 설명하고 숫자형·문자형 자료에서 적용 
가능성을 구분한다.
• 과정·기능: 자료를 정렬하거나 빈도표로 나타내 세 대푯값을 계산·검산하고, 이상치
·분포·자료 목적에 따라 적절한 값을 선택한다.
• 가치·태도: 서로 다른 선택의 근거를 존중하며 ‘공정한 대표’가 맥락에 따라 달라질 
수 있음을 수용한다.
• 디지털 역량: 다음 차시의 앱 결과를 검증하기 위한 계산 및 데이터 점검 기준을 만
든다.

4.3 1차시 선택 기준
• 평균: 모든 숫자 값을 반영하지만 이상치에 민감하다. 자료가 비교적 고르고 전체 수
준을 비교하려는 목적에 유용하다.
• 중앙값: 정렬한 자료의 가운데 위치를 나타내며 이상치에 비교적 안정적이다. 짝수 
개이면 가운데 두 값의 평균이다.

• 최빈값: 가장 자주 나타난 값 또는 범주이며 문자형 자료에도 쓸 수 있다. 없거나 여
러 개일 수 있다.
• 선택은 계산값만이 아니라 자료 유형, 분포와 이상치, 반복 양상, 조사 목적, 표본 대
표성을 함께 고려한다.
4.4 데이터 윤리 안내
• 실제 학생 생활 자료를 공개적으로 비교하거나 개인을 평가하지 않는다.
• 민감한 건강·성적·가정 형편·몸무게 자료는 수집하지 않으며 응답하지 않을 권리를 
보장한다.
• 2차시 앱에서는 실명 대신 번호·별칭을 사용하고 다른 학생의 값을 놀림이나 평가에 
이용하지 않는다.


5. 2차시 지도안: 대푯값 탐정 앱으로 추천을 검증
하라
5.1 차시 목표
• 지식·이해: 숫자형과 문자형 자료에 적용 가능한 대푯값을 구분하고 이상치·분포·목적
·표본 대표성이 선택에 미치는 영향을 설명한다.
• 과정·기능: 생활 자료를 정확히 입력·검증하고 평균·중앙값·최빈값을 검산하며, 앱 자
동 추천을 비판적으로 판단하여 근거 기반 결론을 만든다.
• 가치·태도: 개인정보를 보호하고 조원과 공정하게 합의하며, 예상과 다른 결과를 오
류가 아닌 탐구 기회로 받아들인다.
• 디지털 역량: 앱의 자동 계산과 추천의 유용성·한계를 이해하고 원자료와 활동지로 
결과를 교차 검증한다.

8. 준비·실행 절차와 기술 장애 대응
8.1 교사 사전 준비
1. 교사 PC에서 앱 폴더의 의존성을 준비하고 npm start로 서버를 실행한다.
2. /teacher에서 수업용 반을 만들고 숫자형·문자형 주제, 단위, 글자 답변 허용 여부를 
설정한다.
3. 학생 URL 또는 QR을 준비하고 교사 PC와 학생 기기가 같은 와이파이에 연결되는지 
확인한다.
4. 학생 기기 2대 이상으로 반→조→번호·별칭 입장, 값 제출·수정, 대표 제안·동의까지 
시험한다.
5. 앱에는 그래프가 없음을 확인하고 정렬표·빈도표 활동지, 계산기, 익명 예비 자료 카
드를 준비한다.
6. 민감하지 않은 주제인지 검토하고 개인정보 최소 수집·별칭 사용·수업 후 자료 정리 
방침을 안내한다.
8.2 실행 중 점검
• 자료 공개 전 입력 인원과 자료 수, 누락·중복, 단위·범위, 이상치를 확인한다.
• 앱 계산과 학생 검산이 다르면 어느 단계(입력, 합계, 나눗수, 정렬, 빈도)에서 달라
졌는지 추적한다.
• 앱 자동 추천을 발표하기 전에 학생이 독립적으로 자료 특성과 예상 대푯값을 기록하
게 한다.
• 기기 담당에게 조작이 편중되지 않도록 계산·검증·발표 역할을 순환한다.
8.3 기술 장애 시 종이 활동 대안
