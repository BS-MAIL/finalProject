통계 계산 및 해석 원칙
• 앱은 해당 종목에 실제로 참여하여 값이 입력된 자료 전체를 모집단으로 본다. 자료
가 x₁, …, xₙ일 때 평균은 평균 x̄ = Σxᵢ/n, 편차는 xᵢ-x̄, 분산은 Σ(xᵢ-x̄)²/n, 표준
편차 = √분산(분산의 양의 제곱근)으로 계산한다.
• 표본분산의 n-1은 이 수업에서 다루지 않는다. 결석·미참여 때문에 결론의 적용 범위
가 제한될 수 있다는 점은 자료의 한계로 다룬다.
• 원자료 단위가 회, cm, 초라면 편차와 표준편차는 원자료와 같은 단위이고, 분산은 
각각 회², cm², 초²이다. 분산은 제곱 단위라 직관적 해석이 어렵고, 표준편차는 원자
료 단위라 평균에서 떨어진 정도를 설명하기 쉽다.
• 빈칸은 0이 아니라 계산에서 제외된다. 따라서 분석 전 자료 수를 먼저 확인한다.
• 앱은 결과를 소수 둘째 자리로 반올림해 제시하며, 앱의 계산 연습 판정은 허용 오차 
0.05이다. 중간 계산은 충분한 자릿수를 유지하고 마지막에 반올림한다.

3. CBL 설계

| CBL 요소 | 내용 |
| --- | --- |
| Big Idea | 모두가 참여하기 좋은 체육활동을 데이터로 설계·선택하는 공정한 의사결정 |
| Essential Question | 모두에게 적합한 체육대회 종목임을 판단하려면 자료의 어떤 요소를 고려해야 할까? |
| Challenge | 우리 조의 실제 수행 기록과 산포도, 조원 평가를 근거로 체육대회에 가장 적합한 종목을 추천하고 그 한계까지 설득력 있게 발표하라. |
| Guiding Questions | 평균이 같은데 분포는 어떻게 다를 수 있는가? 편차의 합은 왜 0이 되는가? 왜 편차를 제곱하는가? 표준편차의 단위는 무엇인가? 서로 다른 단위의 산포도를 비교해도 되는가? 추천 점수는 무엇을 반영하고 놓치는가? |
| Engage | 같은 평균·다른 퍼짐의 두 수행 기록을 보고 ‘모두에게 적합함’의 의미를 문제 삼는다. |
| Investigate | 개념을 의미 중심으로 익힌 뒤 실제 기록을 입력·검산하고 통계, 그래프, 평가, 추천 순위를 비판적으로 분석한다. |
| Act | 개인 보고서를 토대로 조 보고서를 생성하여 추천·한계·개선안을 발표하고 다른 조 근거와 비교해 최종 결정한다. |


추천 점수 해석
• 추천 점수는 조원 평가 80점 + 같은 단위 종목끼리 비교한 상대적 일관성 20점, 총 
100점이다.
• 조원은 종목마다 공정성·재미·안전성·준비 용이성의 4요소를 각각 평가한다. 앱은 네 
요소의 개인별 평가를 모아 조 평균 평가를 만들고 이를 평가 80점으로 환산한다.
• 일관성 20점은 같은 단위로 정규화되는 종목들 사이에서 표준편차가 상대적으로 작
을수록 높다. 비교할 같은 단위 종목이 2개 미만이거나 모두의 표준편차가 같아 비교
가 성립하지 않으면 중립값 10점을 부여한다.
• 단위가 다른 종목의 표준편차는 직접 크기 비교하지 않는다. 앱 그래프나 목록에 함
께 보인다는 사실은 비교 가능하다는 뜻이 아니다.
• 표준편차가 작다고 무조건 좋은 종목은 아니다. 지나치게 쉽거나 재미없는 활동도 기

4. 설계 의도와 학습자 분석
4.1 설계 의도
학생은 분산 공식을 계산 순서로만 외우면 값이 무엇을 뜻하는지, 왜 평균만으로 분포를 설
명할 수 없는지 이해하기 어렵다. 같은 평균·다른 퍼짐에서 출발해 편차, 편차 제곱의 평균, 
원자료 단위로 돌아온 표준편차를 연결한다. 실제 수행 자료와 앱의 즉각적인 통계·그래프
는 해석 시간을 확보하고, 손계산·2인 대조·단위 점검은 자동 산출의 맹신을 막는다. 추천 
순위와 학생 판단이 다를 수 있도록 하여 수학적 근거와 가치 판단의 역할을 구분한다.
4.2 학습자 분석
• 선행 상태: 평균을 계산하고 막대그래프를 읽을 수 있으나, 평균이 같으면 자료도 비
슷하다고 판단하기 쉽다.
• 예상 어려움: 편차의 음수, 편차 합이 0인 이유, 제곱 단위, 분산과 표준편차 혼동, 
n과 n-1혼동, 서로 다른 단위의 표준편차 직접 비교.
• 참여 차이: 신체 수행 수준과 디지털 숙련도가 다르므로 기록의 높고 낮음을 개인 능
력 서열로 사용하지 않고 역할을 순환한다.
• 지원 방안: 계산 틀, 단위 문장틀, 계산기 허용, 짝 검산, 익명 번호·별칭, 수행 대체 
역할(측정·기록·안전 확인)을 제공한다.

7.1 종목과 스테이션 운영
• 교실형 권장 조합: 종이컵 탑 쌓기(개) + 콩 옮기기 30초(개) + 10초 감각 맞히기(오

간에서 뛰지 않고, 콩을 입에 넣지 않으며 떨어진 콩은 즉시 치운다.

리뛰기(cm), 농구 자유투 10개(성공) 또는 한 발 서 있기(초) 중 하나. 앞의 두 기본 
종목만 같은 단위로 표준편차를 상대 비교한다. 충분한 간격·미끄럼 점검·대기선을 
확보하고 줄넘기·점프·공 사용 종목은 교사 승인 후 운영한다.

2~3개를 만든다. 학생 UI의 필수 학번·이름 칸에 사용할 허용 형식(예: 학번 칸 조번

는다.
• 공용 태블릿의 브라우저 localStorage에 앱 상태나 입장 세션이 남을 수 있다. 사용 
후 해당 사이트 데이터와 저장된 세션을 정리하고, 다음 반이 이전 반을 열람하지 못
하도록 확인한다.
• 사진 촬영·업로드는 선택이며 학생·보호자 및 학교 기준에 따른 사전 동의를 확인한
다. 얼굴·명찰·위치 정보가 드러나는 사진은 피하고 미동의 학생은 촬영하지 않는다.
• 업로드 사진 URL은 인증 없이 접근 가능한 공개 경로일 수 있고 서버가 public, 
max-age=31536000, immutable로 장기 캐시하므로, 삭제 후에도 기기 캐시에 남을 
가능성을 전제로 한다. 민감한 사진은 애초에 업로드하지 않는다.
• 수업 종료 후 보고서/PDF 보관 여부를 확인하고 앱에서 불필요한 반·학생·사진 데이
터를 정리한다. JSON 백업은 사진 자체를 포함하지 않으므로 사진 보관·삭제를 별도
로 확인한다.
데이터 윤리
• 개인 기록은 성적·운동 능력 서열화나 놀림에 사용하지 않는다. 발표에는 가급적 조 
통계와 익명 축만 제시한다.
• 측정 실패·미참여는 0으로 조작하지 않고 빈칸으로 두며, 제외된 자료 수와 이유를 
밝힌다.
• 작은 조 자료를 학급 전체나 모든 학생에게 일반화하지 않는다. 측정 오차, 연습 효
과, 순서 효과, 평가의 주관성, 결석·미응답을 한계로 기록한다.

| “편차를 더하면 0인데 왜 쓰나요?” | 평균 기준 왼쪽·오른쪽 거리가 상쇄됨을 인정하고, 거리의 크기를 남기기 위해 제곱하여 평균 냄을 연결한다. |

| “초와 cm의 표준편차 중 작은 것이 더 공정하죠?” | 측정 단위와 척도가 달라 숫자 크기를 직접 비교할 수 없으며 같은 단위 종목 안에서만 상대 비교하게 한다. |

| “추천 순위가 정답이죠?” | 평가 80점과 일관성 20점이라는 설계된 기준의 결과일 뿐이다. 빠진 가치와 자료 한계를 찾아 동의 또는 반박하게 한다. |
| “왜 일관성 점수가 10점인가요?” | 같은 단위 비교 종목이 부족하거나 모두 같으면 상대적 순위를 정할 수 없어 중립 10점을 주는 규칙이라고 설명한다. |
| “앱 계산과 제 계산이 달라요.” | 입력값·자료 수·빈칸·평균·편차 제곱합·나눗수 /n·중간 반올림 순으로 추적한다. 최종 허용 오차는 0.05이다. |
| 개인정보가 화면에 보임 | 투사를 즉시 중지하고 번호·별칭으로 고친 뒤 재개한다. 노출된 사진·자료는 학교 절차에 따라 삭제·보고한다. |
| 기술 장애로 앱을 못 씀 | 익명 예비 기록표, 손계산, 4요소 평가, 추천 포스터와 구두 발표로 동일한 Challenge를 계속한다. |
